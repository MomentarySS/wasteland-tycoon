# 修复顺序决策 · 正典 vs 小说

> **日期**：2026-09-05
> **适用**：《废土大亨》世界观正典（final）与小说设定（novel）的并行修复
> **结论先行**：**不要串行，按依赖分层。**「等正典稳定再修小说」在本项目中是过度保守，且「正典稳定」本身是伪终点。

---

## 一、核心判断：依赖是单向且稀疏的

把小说侧 15 项必修逐条映射到它所依赖的正典条目，结果如下：

| 小说项 | 依赖的正典条目 | 该条目状态 | 是否阻塞 |
|---|---|---|---|
| A1 血脉死结（第三代 ↔ 22 岁） | 1.5 / 3.1（出口-7 封闭 25 年） | **稳定** | 否 |
| A2 伊登门内/门外 | 1.4 / 1.5 | **稳定** | 否 |
| A3 手册来源 | 1.4 | **稳定** | 否 |
| A4 守誓协议 AB 0–24 | 3.1（AB 24 自检） | **稳定** | 否 |
| A5 档案员位置 | 4.2 | **稳定** | 否 |
| A6 第七日 | 1.5 | **稳定** | 否 |
| A7 配给记账员 | 1.5 | **稳定** | 否 |
| A8 钥身时间线 | 无（4.4 为小说原创） | — | 否 |
| A9 雷娜动机 | 无（小说内部） | — | 否 |
| D1-1 / D1-2 服役年数 | 3.1（AB −18 三井竣工） | **稳定** | 否 |
| D2-1 五种秩序 | 4.3 | **稳定** | 否 |

### 结论

**15 项里只有 1 项真正被正典阻塞。** 其余 14 项依赖的都是正典**已稳定**的历史、地理、人物栏与时间线——这些在 v2.0 融合版中已经定型。

更关键的一点：**优先级最高、卡住「能不能动笔」的 A1（血脉死结），恰恰是完全不依赖任何待补数据的。** 它是纯算术问题。等正典不会让 A1 变得更容易，只会让它拖得更久。

## 二、正典侧 5 项修改的性质分类

「先修正典」听起来稳妥，但要看清楚这 5 项到底是什么性质：

| 编号 | 修改内容 | 性质 | 是否存在设计决策 |
|---|---|---|---|
| D4-1 | 补三哨 200 / 电站 150 / 净水站 160 | **记录**（答案已在 `tiles.json`） | 无 |
| D5-1 | 补升级费 = 地价 | **记录**（答案已在 `rules.js:46-47`） | 无 |
| D5-2 | 补租金公式 | **记录**（答案已在 `rules.js:74`） | 无 |
| D8-2 | 修正据点救济的条款引用 | **纠错**（第五条是抽成，非安抚金） | 极小（改引用 or 加附则） |
| **D6-1** | 虫洞派「棋盘中央的蓝光」位置 | **叙事决策** | **有** |

**5 项里 4 项是「把代码事实抄进文档」，答案唯一、无争议、不触碰任何叙事。**

这类修改：
- 耗时约 30–60 分钟
- **不可能引发返工**（事实就是事实）
- **零波及面**（不改动任何历史事件、人物、地点、结局）

**唯一需要「想清楚再定」的是 D6-1**——因为它是二选一：改 1.9 的措辞，还是改 3.3 的地点？本清单已给出推荐解（保留民间误称并点破），但这一条值得单独过一遍。

## 三、执行顺序：分四层，而不是分两个文档

```
L0  立即并行（无依赖）
    ├─ 正典：D4-1 / D5-1 / D5-2 / D8-2  ← 抄代码，半小时
    ├─ 正典：D6-1                        ← 唯一需决策，单独定
    └─ 小说：A1 → A2 → A3               ← 血脉死结优先，它是所有人物关系的根
              A8 / A9                    ← 小说内部，随时可做
              D1-1 / D1-2 / D2-1 / D3-3 / D8-1

L1  依赖 L0 的数据结果（正典补完即可做）
    └─ 小说：D5-3 开局资金  ← 需要 1380 / 780 / 180 这几个数才能定

L2  依赖 L1（资产曲线确定后）
    ├─ 小说六部资产曲线重排（一部 180 → 二部 1380 → …）
    ├─ 第四部破产 / 崩溃的杠杆设计
    └─ 第五部深采队的争夺标的（裂谷电站归属，D4-2）

L3  结构与视角（改动面最大，放最后）
    └─ 小说：D2-2 补入玛拉·凯恩  ← 需重新分配视角百分比
```

### 为什么 A1 排第一

A1（「第三代出仓者」与「雷娜 22 岁」互斥）不依赖任何外部数据，但它**卡住所有人物关系的根**——雷娜是第几代、伊登是她什么人、她为什么姓摩根、祖宅为什么是她的执念。

若先写第一二部，A1 修完后**全稿返工**。这是本项目唯一一处「不修就不能动笔」的问题，且它现在就能修。

### 为什么 D2-2（玛拉）排最后

不是因为它不重要——恰恰相反，它是本轮最扎眼的遗漏（结局见证人 + 第四部道德对手盘双重缺失）。而是因为它**改动面最大**：补一个占 6% 视角的角色，要从霍尔特（12%）和塞拉（5%）手里匀篇幅，意味着视角结构的整体重排。

**结构改动放最后做，避免被前面的细节修改反复推翻。**

## 四、判断依据：一个条目会不会再变？

「等正典稳定」的问题在于——**正典永远不会完全稳定**，它是随游戏代码迭代的活文档。把「正典稳定」设为动笔前置条件，小说永远动不了。

正确的判据不是「稳不稳定」，而是「**这个具体条目会不会再变**」。本项目正典条目分三类：

| 类型 | 判据 | 例子 | 会不会变 |
|---|---|---|---|
| **代码锚定** | 数值写死在 `tiles.json` / `rules.js` / `difficulty.js` | 地价、租金公式、格数、派系 id、开局资金 | 不会（除非改代码，那是重大决策） |
| **叙事锚定** | v2.0 已融合三份草案的历史/人物/地名 | 灰日三幕、五区、人物栏、焚年总表 | 基本不会（刚融合完） |
| **故意留白** | 正典明写「不设官方解释」 | **虫洞真相、确认官下落、衰减期物理终点** | **永远不会**——它在等小说去填 |

### 第三类最关键

**正典故意留白的地方，恰恰是小说该先动的地方。** 因为正典按定义不会给你答案，等下去没有意义——小说就是这些空缺的「答案生产者」。

具体到这里：
- **确认官下落**：正典明写「不设官方答案」。小说底稿 3.1 已经给出了完整答案（协同抗命）。这是小说的原创区，正典不会改，也不会来抢。
- **虫洞真相**：正典「不设官方解释」。小说 3.3 给出「盆地是一根天线」。同样是小说原创区。
- **衰减期物理终点**：正典留白，底稿自评也建议「留到第六部定稿前再锁死」。**这一项必须等小说写到第六部才有答案。**

**在留白区等正典，是无效策略。**

## 五、反过来：什么时候必须先修正典？

### 触发条件（满足任一条 → 正典先行）

1. **正典条目是硬事实，且小说引用错了**
   → 例：D1-1 / D1-2。三井 AB −18 竣工是代码/正典双锚定的事实，序章写「服役三十年」「二十六年条令」都错。**这类必须先查正典，否则小说改了也可能再错。**

2. **正典是命名权威**
   → 例：D8-1 格拉夫顿。五区名、三派 id、地标专名以正典为准，小说跟着改，不存在商量。

3. **小说要从正典借人物 / 地点**
   → 例：D2-2 玛拉、D3-3「掠夺者军阀」地契。借用前必须确认正典里这个人物/地点的定义，否则会借错。

4. **改动会波及游戏侧**（事件卡、UI 文案、图鉴、TTS）
   → 若要改的是地价、格数、派系 id 这类代码锚定项，那是代码级改动，需走「先改 `tiles.json` 与正典第二章，再改规则代码」的规约（正典附录 C 第 1 条）。

### 什么时候反过来先修小说？

1. **小说是正典的试验田**
   → 例：科尔的整套设定（买地契是为信号链路、井口派施主、辩经收束）目前只存在于小说。若这些未来要回写正典，应**先在小说里跑通、稳定后再回写**，而不是先在正典里定死。

2. **正典空缺只有写故事才能发现答案**
   → 例：衰减期的物理终点。这种不能先锁正典，只能等小说写到第六部。

3. **正典改动成本远大于小说，且会波及游戏平衡**
   → 例：若要改 44 格地价或租金公式，那是平衡性改动。**先在小说里验证叙事效果，值得改再动代码。**

## 六、边界纪律：防止小说污染正典

并行推进的最大风险不是返工，是**小说原创设定反向渗入正典**。三条硬规矩（底稿附 2 已声明，此处重申）：

1. **剧透隔离**：小说揭底的真相（确认官抗命、虫洞本质、密钥下落）**不得回写**游戏事件卡、UI 文案与正典。游戏侧永远维持「不设官方解释」。
2. **新增人物回写规则**：小说原创人物（雷娜、伊登、罗尚、温德尔、格拉夫顿、沃斯、科尔、小滤）若需进入游戏事件卡，**须先回写正典人物栏并做剧透脱敏**。
3. **原创专名补登**：D6-5「裂谷量子防务工程」是小说原创专名，正典 1.2 无落点——要么回写正典，要么小说改用正典措辞「裂谷防务工程」。不能让它悬着。
