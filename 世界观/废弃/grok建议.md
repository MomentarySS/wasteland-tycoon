## 一、总评（先看结论）

| 维度 | A · GLM | B · Grok | C · MiniMax |
|---|---|---|---|
| 设定完整度 | 中高：主题完整，规则细项有缺 | 高：与代码表几乎对齐 | 表面最高：章节最多，掺假也最多 |
| 逻辑一致性 | 中：内部自洽，但和闯关「第七日」打架 | 高：时间线、密钥、格子机制能对上 | 低：格子计数、任务链、密钥来源多处与代码矛盾 |
| 与玩法契合 | 高（主题）/ 中（机制） | 高（机制）/ 中（主题） | 低：大量「尚未实现却写成已落地」 |
| 最适合干什么 | 提供「为什么这是大富翁」的时代借口 | 当文案与系统的权威对照表 | 提供章节目录与「机制必须有世界观解释」的写法 |

**一句话**：不要三选一原文当 canon。用 **B 做骨架（机制与地名）**，用 **A 做主题（地契大爆炸、路契大亨、骰子即废土）**，用 **C 做目录体例（牌堆/任务链/模式分章）**——但 C 里所有「已落地奖励、派系终局、HP、第四条铁路」必须先对照代码删掉。

## 二、对照基准里，三份都不该写错的事实

写建议前先钉死实现，避免把「写得好看」误判成「写得对」。

| 项目 | 仓库事实 | 谁写错了 |
|---|---|---|
| 可购地产 | 20 块五色地产 + 3 铁路 + 2 设施 | C 写成 30 块地产 |
| 事件格 | 6 格 | C 写成 8 格 |
| 铁路 | 阿尔法 / 布拉沃 / 查理 **3** 哨，租金 25/50/100 | C 写成 4 条且「投骰换区」 |
| 设施租金 | 1 座 ×4 骰点，2 座 ×10 | C 写成一律 ×10 |
| 绿洲 | +25 盖 | C 写成 +30 |
| 矿洞 | 深采/浅采二选一，不是落地扣血 | A 写成踩入即付医疗费 |
| 赏金站 | 首富领赏，其他人向其缴费 | A 写成接通缉单；C 写成击杀触发 |
| 国会掩体 | 休整（盖+道德）或免费升级一处地产 | A 写成密钥交易所 |
| 密钥顺序 | 阿尔法 → 布拉沃 → 查理，来自任务链与随机掉落 | A 把三哨通行权绑密钥；C 把密钥写成占三哨胜利 |
| 任务链 | 无 `chain_blackmarket` / `chain_route` / `chain_enclave` | C 增写这三条并给了不存在的道具奖励 |
| 声望 | 小整数累加，无商店折扣档 | C 写成 −100～+100 与派兵协助 |
| 叙事种子 | 7 种（含平局），无「浴火重生」 | C 多写破产种子 |
| 遗产衰减 | 闯关第四～六章 `decayPerTurn` | C 写成遗产模式每 8 回合 +5 |
| 棋盘 | 每局洗牌，据点固定 0 格 | C 把北弧南弧写成固定地理；A 未提洗牌 |
| 派系 id | `eagle`=掠夺者，`tech`=残存政府 | A 另给政府「白鹰」别名，易与 `eagle` 撞车 |
| 事件卡 | 80 张（电台 36 / 手册 28 / 密使 9 / 遗迹 7） | C 的「80+」数量对，分堆枚举不完整且有杜撰链 |

闯关开场原文是「末日第七日……逃出隔离区」，不是「地契市场开张两年后的第一代寡头」，也不是「回响 137 年后推开铁门、腰别 10mm」。任何时间线必须先消化这一句。

## 三、逐份评点

### A. GLM 5.3《废土大亨》

#### 完整度

有完整的四章骨架，并且真正回答了经营游戏最难的一问：**废土上为什么突然能买地收租？** 「冲突打到破产 → 地契大爆炸把 44 处资源点折成路契」是三份里最像「经营游戏世界」的一刀。

缺的是实现层：道具卡十张未列、突变因子一笔带过、遗产商店与难度档缺席、十六条链只点名不写抉择、抵押/赎回/黑市 80 盖偷地/矿洞深浅采均未写准。特殊格有表，但多格机制被改写成更「故事」的版本。

#### 逻辑一致性

文档内部相当自洽：瓶盖本位 → 商路战争 → 合约战争太贵 → 地契取代枪杆子 → 衰减章是「红利期结束」。骰子被解释成「计划赶不上废土」，比另外两份都更像大富翁。

与现有叙事的裂缝：

1. **时代对不上闯关。** 纪元 43、地契落地两年、第一代大亨已成气候，和「第七日刚逃出隔离区、半箱瓶盖」不是同一开局。
2. **灰烬日写成 2077.11.02**，与辐射系列大战日相同，IP 与「轻量致敬」边界过近。
3. **「白鹰」** 用来称呼残存政府，而存档里 `eagle` 是掠夺者。文案组很容易写反。
4. **三哨 = 密钥传说** 过绑。代码里买满铁路只加过路费，密钥走 `nuke_chain_*` 与矿洞/黑市/电台阵列掉落。
5. 安全格写成净水修道院、税写成银行+法统税，是好人格化，但事件卡与 TTS 里并无这些专名，会变成两套口头传统。

#### 与玩法契合

主题契合是三份里最好的：玩家身份是 **路契大亨** 而不是持枪幸存者；破产是「你倒下的地方成为下一个大亨的起点」；尸潮季既是灾害也是药价商机——这都对准圈地、收租、事件二选一。

机制契合被故事带偏：矿洞、赏金、掩体、铁路的结算若按本文去写事件，会和 `resolveTile` 对不上。道德「好事件向你倾斜」也夸大了：现行道德主要改章节旁白与结局，不改四牌堆权重（权重改动来自叙事种子/突变，不是实时道德条）。

#### 优点

- 「枪杆子打不动了，废土开始用钱说话」——经营作的一句钩子。
- 每块地产有一句能进图鉴的闲话（废场练手、毒巢现金流、基因场垄断饭碗）。
- 黑市公会、废土银行、净水修道院给税/拍卖/安全格找到了「谁在收钱」。
- 衰减暗线（红利结束、新地契不再产生）比单纯「尘暴刮盖」更像经营破产。
- 明确玩家无强制阵营，「立场跟着利益走」，符合对抗模式。

#### 缺点

- 特殊格机制多处改写。
- 与 FPS 姊妹文绑定过紧（冲突合约、白河净水厂），2D 经营文档不应依赖未落地射击设定。
- 2077 大战日、白鹰别名有后续风险。
- 缺少洗牌、道具、突变、遗产点公式这些已经在玩的系统。

#### 改进建议（针对 A，不改原文，供下一版）

1. 把「现在」改成与第一章闯关兼容的两种口径之一：要么玩家是地契元年的第一批投机者（第七日=市场开放第七天），要么大亨时代是背景、玩家仍是刚出门的投机新兵。
2. 废止「白鹰」或改成与 `eagle` 无关的名字（例如「协议部」「掩体当局」）。
3. 特殊格按 `rules.js` 重写一句「机制原文」，故事放在第二句。矿洞必须保留深/浅采；赏金必须保留首富规则。
4. 三哨与密钥解绑：铁路是动脉，密钥是漏电的旧系统。
5. 补一页：十张道具卡、垄断/升级/抵押、黑市三选项、遗产七种种子。
6. 去掉 2077.11.02，改用文档自有纪年。

### B. Grok 4.6《废土大亨》

#### 完整度

四章齐全，附录有地点速查。机制覆盖面最广：五区垄断与升级、隔离出狱三法、黑市偷地/淘卡、赏金、绿洲、虫洞、矿洞深浅采、掩体二选、铁路与设施公式、十卡、突变世界观化、四种模式、六章目标数字、十六条链的抉择核、密钥掉落源、遗产与终局阈值。

缺的是「经营幻想」的那一层：地产少有 GLM 那种市井一句；没有解释「废土为什么同意把命换成地契」；黑市/税卡/安全格没有人格化机构。时间线用焚年，完整但偏编年史，不像开局旁白。

#### 逻辑一致性

与代码一致性最高。密钥顺序、洗牌（路在变、地方还在）、道德不改租金、`eagle/survivor/tech` 对照、核弹绝对胜利、衰减数值 8/12/15，均可直接给程序当注释。

仍有设定层选择，不是代码错误：

1. **焚年 0–32、出口-7 封闭二十五年** 是补全，不是 `events.json` 原文。与闯关「第七日」兼容（开门后第七天），但和 A 的纪元 43、C 的 R.A. 137 不能并存。
2. **手册派 / 井口派 / 协议派 / 虫洞派** 是解释框架，卡牌里没有教派专名——可以用，但应标「民间口头，非第四势力」。
3. 爆心区作为棋盘中央靶场，对齐核弹过场，比 C 把视觉中心写成「避难所出口」更贴 `nuke` 与中央雷达图。

#### 与玩法契合

机制契合最好：几乎每条规则都能在局内碰到。四种模式的「世界读法」对设计有用（对抗=圈地战争，闯关=一个人的账本，合作=共用营地，遗产=上一代改气候）。

主题契合弱于 A：玩家仍像「走格子的幸存者」，不像「入市的大亨」。森林区写主导资源「废铁燃油」，正确，但不如「先买个废场练练手」能进加载文案。

#### 优点

- 可当开发圣经：改格子先改 JSON 再改第二章，约法十条可执行。
- 特殊格没有把愿望写成现状。
- 任务链用「伤口 + 抉择核」压缩，适合给事件作者当索引，且链名与文件一致。
- 明确射击不写进本文，避免 2D 文档被 FPS 方案污染。

#### 缺点

- 「为什么是大富翁」不如 A 锋利。
- 单点地产缺乏图鉴级描写。
- 突变表未列全 25 个（指向源码），文案组仍要打开 `mutators.js`。
- 焚年、出口-7 若作为对外 lore 发布，需在 README/手册里统一，否则和 GLM/MiniMax 纪年混用。

#### 改进建议（针对 B）

1. 吸收 A 的开篇：用一节「地契何以合法」放在第一章，不要改格子规则。
2. 为 20 块地产各补一句市井闲话（可直接改编 A 的 2.2–2.6）。
3. 给税/安全/拍卖各指定一个**可选**人格（银行、停火口袋、黑市公会），并写明「未入事件卡前只作口吻」。
4. 把 25 个突变补全进附录，避免「其余见源码」。
5. 在时间线旁加一行：与 `CHAPTER_INTROS` 第一章「第七日」的对照关系，防止后人改成百年史。

### C. MiniMax《origin · 大富翁版》

#### 完整度

看起来最像「完整设计文档」：十章 + 两附录，牌堆、任务链、派系、核弹、四模式、25 突变、7 传承、10 道具、名词表、维护原则一应俱全。数量上 80 张事件卡说对了。

问题是 **完整度掺了未实现内容**，比缺写更危险。文案按本文去写，会做出游戏里不存在的：HP、净水券、EMP 雷、燃烧弹、虫洞石、垄断卡、派系终局（麦克森/艾玛/冰湖）、声望商店、占三哨得密钥、第四铁路、30 块地产。

#### 逻辑一致性

内部编年（回响 → 长灰百年 → R.A. 137）可以当另一套故事，但和本游戏的密钥设定互相打脸：C 让三哨在灾后 90 年才建成，而电台任务链写的是旧自动化发射系统自检、井口从沉睡中抬头。旧系统不可能在灾后才挖井、又同时是灰日打出去的那套握手协议。

与代码的硬冲突见第二节表。另外：

- 「买下一片颜色就是向该派系表态」不成立：五区对三派，森林/沼泽没有对应派系；买摩根镇废场不是加入掠夺者。
- 发射核弹后「所有玩家结算暴君」不成立：发射者绝对胜利，传承种子是「核爆余烬」，不是全员暴君。
- 赏金写成击杀、铁路写成换区，是 FPS 文档语气漏进桌游。
- `chain_blackmarket` / `chain_route` / `chain_enclave` 在 `events.json` 中不存在；黑市线实际是 `chain_empire_*`。
- 遗产「每 8 回合 +5 衰减」无对应实现。
- 叙事种子「浴火重生」不在 `NARRATIVE_SEEDS`。
- 国会掩体深 280 米、1873 次打击、1.2 亿→7 万、10mm 手枪、Enclave、铁锤麦克森：数字与辐射 IP 过近，且无游戏数据支撑。

#### 与玩法契合

意图正确：「世界观必须有玩法承载、机制必须有世界观解释」。第十章对照表这个体例值得留。

执行上大量「奖励已解锁」会让玩法文档变成空头支票。派系声望若按 ±100 和派兵协助去设计，和目前密使牌 +1/+2 的体量不是同一个游戏。合作「任一队友破产即失败」需核 `game.js`：现行是共享目标，人类破产才终局，不宜写成铁律。

#### 优点

- 结构最适合「给策划的说明书」：牌堆、链、模式、突变分章，检索快。
- 事件触发流程（权重 → 前置 → 二选一 → flag）是对 `missions.js` 的正确概括。
- 25 突变表、道具表、遗产点公式与源码高度同构（这一块比 GLM 全、与 Grok 相当）。
- 维护原则（改格子改哪一节）可直接抄到融合版。
- 「这不是传统大富翁，每一步都在赌命」适合商店页文案。

#### 缺点

- 把愿望清单写成 v1.0 已落地。
- 格子算术错误会连带美术分区（北弧南弧、正北三哨）全部不可用——何况棋盘还洗牌。
- IP 风险高于另外两份（Enclave、麦克森、10mm、精确到日的核大战）。
- 与 FPS 文档交叉引用「冰湖停战、三波打击」使 2D 经营设定无法独立阅读。

#### 改进建议（针对 C）

1. 先做一次「已实现 / 规划中」二分。凡 `events.json` 没有的链、`cards.js` 没有的牌、`narrative.js` 没有的种子，一律移入「扩展愿望」。
2. 重数 44 格：20 地产、3 铁路、2 设施、6 事件、3 税、2 安全，其余各 1。
3. 密钥来源改回任务链 + 矿洞/黑市/阵列掉落，删除「占哨即得钥」。
4. 删 HP 体系；本作没有生命条，生存压力是瓶盖与隔离。
5. 派系不要等于五区颜色；最多说灰堆「气口」近掠夺者、毒谷近响应者、裂谷近政府。
6. 棋盘地理改为「洗牌后的商路顺序」，视觉中心是爆心/雷达，不是起点。
7. 削弱辐射 IP 专名；麦克森/艾玛/冰湖可改成匿名军阀与停火传闻。

## 五、必须先裁定的冲突（融合前三选一）

不裁定就无法出「唯一权威」。建议默认如下，括号内为理由。

1. **纪年**  
   选短当代（开门后以「日/季」计），不选 2077 大战日，不选 R.A. 137。  
   （对齐 `CHAPTER_INTROS`；避开辐射大战日；六章衰减是季节不是世纪。）

2. **玩家身份**  
   对外：路契大亨；对内开局：刚出隔离区的投机新兵。  
   （A 的钩子 + B/闯关的镜头。不要开局就发 10mm。）

3. **三哨与密钥**  
   铁路是买得起的动脉；密钥是旧发射系统的漏电，乱序无效。  
   （B + 代码。A/C 的「占哨=握井」只可作民间误传。）

4. **棋盘地理**  
   地点永恒，路径每局重铺。中央是爆心，不是出生点。  
   （`shuffleBoard` + 核弹落点。）

5. **派系与五区**  
   三派 ≠ 五色。灰堆/毒谷/裂谷只有「气口相近」。  
   （避免买废场变成加入血帮。）

6. **安全格与税**  
   机制保持中立口袋与定额税；修道院/银行仅作口吻，进卡再转正。  
   （防止 TTS 与设定专名两套。）

7. **未实现内容**  
   派系终局、HP、新道具、假任务链、声望商店，一律标「扩展」，禁止出现在 v1 canon。

8. **IP 专名**  
   棋盘已有地名可保留（与 `tiles.json` 一致）；新增不要用 Enclave、麦克森、10mm、2077.11.02。
