> **正典依据**：本文的一切内容都能在《废土大亨》既有设定中找到出处或合理延伸——五区、三派、瓶盖、三井密钥、44 处地标、突变因子、任务链、六章结构，均为桌游已落地资产的射击化翻译。

>

## 约法（先于一切设计的铁律）

1. **地点先于枪皮。** 每张地图必须能指回姊妹文档第二章的一个地标（或本文扩展槽）；不做无出处的沙漠盒子。
2. **五区名与三派存档 id 不改**：掠夺者 `eagle` / 响应者 `survivor` / 残存政府 `tech`。
3. **瓶盖是唯一硬通货**；回合买枪，经济可带入下一回合，不可带入下一张地图。
4. **密钥只认 阿尔法 → 布拉沃 → 查理**；UI 与关卡脚本必须拒绝乱序。核平是终局，不是普通超杀奖励。
5. **匹配默认两队对抗**（铁鸦 vs 哨卫）；三派枪感是队皮与战役阵营，第三方只做地图 NPC 或周轮换，不塞进天梯。
6. **道德与声望不改伤害表、弹道与爆头倍率**；只改开局条件、可购战术道具、中立区态度与战役结局。
7. **禁止无预兆传送**：虫洞必须有 1.5 秒可见预兆 + 音效。
8. **辐射区必须有盖革声**。无声即无辐射。
9. 不把大富翁回合结构（掷骰、买地弹窗）搬进射击 HUD。
10. **FPS 战局结果不得回写桌游存档**；桌游结局可作为本作战役的「世界状态」修饰（如核爆余烬开局），需玩家明确导入。

# 第一章 · 世界背景（作战简报）

## 1.1 战场是哪里

阿帕拉契亚盆地。灰日（焚年 0）的核爆把它撕开，焚年 25 出口-7 开门后它重新变成可争夺的环形领地。到**焚年 32**——本作默认「现在」——五区咬合、三派分食、三井未眠，与《废土大亨》处于**同一年**。

盆地外没有可玩的前线：更高辐射、更密尸潮、已死的旧国边境，只作为地图边缘的不可进入区与天空盒。灯、水、枪和名字都在圈内。盆地中央的**爆心区**是灰日留下的玻璃化焦土，查理井的默认靶标锁在那里——它不是常规出生图，是终局舞台。

完整前史（镀铁时代、灰日、封门二十五年、第七日、地契大爆炸）见姊妹文档第一章。合约兵只需要记住四句话：

1. 旧世界把最后的按钮交给了机器（守誓协议）。
2. 机器在灰日执行了一次靶场校准，三名确认官失联，发射锁死。
3. 系统从未下线，仍在频段里等三枚密钥重新握手。
4. **两年前，战争被折算成了地契；而地契的每一次易主，依然要先流血。**

## 1.2 冲突合约：本作的世界观地基

焚年 27，黑市公会与废土银行牵头确立**冲突合约制度**——瓶盖战争的直接产物，也是理解本作的钥匙。制度原文刻在废土银行总行大厅的铜板上，共五条：

> 一、资源点归属争议，以**定点小队冲突**裁决，单队不超过十人；
> 二、冲突区域、时限与胜负条件由**仲裁者**（黑市公会与废土银行联合体）公示；
> 三、阵亡者的装备归胜方，遗体归原属势力——**人可以死，规矩不能死**；
> 四、波及平民者，全员上黑市通缉榜；
> 五、仲裁抽成百分之十，概不赊账。

第五条让这套制度运转至今，而且运转得很好。这套制度血腥、荒谬，却意外「公平」，于是被所有势力默认。它把废土的战争切碎成了**几分钟一段、十人对十人**的局部绞肉机。

焚年 30 地契大爆炸之后，合约非但没有消失，反而更值钱了：**地契决定谁收租，合约决定地契值多少。** 大亨们在环线上买下一块地，真正撑起那张纸的，是愿意为它开火的合约兵。每一场爆破、护送、营救的背后，都站着一位数瓶盖的雇主。

而这，正是玩家参与的每一场对局的世界观真相：**你不是在打一场战争，你是在履行一份用瓶盖计价的合约。**

- **每场对局** = 一份冲突合约，分上下半场（攻防互换——合约规定系列赛双方必须换边，「光会守的人不配赢」）；
- **每回合** = 一次定点冲突，限时，目标达成或一方全灭即结算；
- **阵亡不回合内复活** = 「合约减员」——仲裁者只统计站到最后的人；
- **回合间买枪** = 整备阶段，双方在各自营地用瓶盖采购装备；
- **遵守规则的原因**：毁约者上黑市通缉榜，那是全废土唯一「见字即杀」的名单。**不遵守的人早死了。**

## 1.3 当代三条作战法则

1. **控点即生存。** 战役中同区连胜 = 该区地图买枪折扣与额外烟雾/护甲——对应桌游的同色垄断。
2. **动脉决定转点。** 控阿尔法 / 布拉沃 / 查理哨打开铁轨捷径；控裂谷电站改灯光；控沼泽净水站给己方回血光环。
3. **井口仍在监听。** 战役集齐密钥可发起井控协议。起爆后没有加时谈判，只有撤离或与棋盘一同核平。

衰减季已经开始：辐射尘暴从间歇变为季节。对应规则是**风暴回合**——视野缩短、户外持续掉血、室内与掩体升值。

## 1.4 生存三铁律（角色行为逻辑）

1. **水比血贵。** 为一口井可以签十份合约，但没人会为一句道歉开枪——因为子弹也要钱。
2. **面具即门禁。** 毒谷看面罩认人，沼泽看船票认人。每个区的通行信物都是天然的势力识别物。
3. **合约大于命，命大于脸。** 这解释了为什么对局双方遵守回合、时限与胜负条件。

## 1.5 四套解释，决定 NPC 开不开门

与姊妹文档 1.9 同源。这些解释**不改爆头倍率**：

| 解释 | 谁信 | 对交火的影响 |
|---|---|---|
| 手册派 | 响应者、多数营地 | 中立摊主、伤员、商队；误伤会拉仇恨、锁针剂 |
| 井口派 | 拾荒客、部分军阀 | 更愿卖爆弹与扰射，更恨拆井的人 |
| 协议派 | 残存政府 | 税卡、无人机、掩体闸机认「证件」 |
| 虫洞派 | 遗迹猎人 | 异常回合的传送口由他们标记 |

# 第二章 · 阵营与人物

## 2.1 对抗双方（匹配默认两队）

冲突合约不问出身，只问站哪边。天梯匹配的两支图腾队，是合约市场上最大的两家「乙方」：

### ■ 铁鸦掠袭团（IRON CROWS）—— 进攻方图腾

掠夺者联军的精锐合约部队，由「碎轮」瓦戈麾下各血帮抽调的破堡手与收债队组成。信条：「天上掉不下来的，就去抢。」装备混杂、打法凶悍，擅长爆破、渗透与先手突袭。

- **视觉识别**：锈红涂装、鸦羽标记、粗糙厚甲；
- **枪感**：霰弹、土制炸药、轻机枪守口；破门与守口是长处，纪律差、复杂室内弱；
- *在爆破类模式中，铁鸦永远是「安放井控模块 / 摧毁目标」的一方。*

### ■ 哨卫团（THE WARDENS）—— 防守方图腾

响应者体系的常备武装，成员多为据点守军、退役商队护卫与「救援先于立场」的信徒。编制正规、火力克制，擅长防守、反制与阵地战。

- **视觉识别**：蓝盾臂章、响应者背心、荧光绿识别灯；
- **枪感**：中距步枪、烟雾、针剂、盾式推进；救人、守点、护车是长处，缺重火硬刚堡垒；
- *在爆破类模式中，哨卫永远是「守卫目标 / 拆除模块」的一方。*

> **换边合理性**：合约第二条规定系列赛攻防互换，因此两队玩家都会体验两种作战哲学。

## 2.2 三大派系（战役阵营 / 队皮 · 存档 id 与桌游一致）

| | 掠夺者（`eagle`） | 响应者（`survivor`） | 残存政府（`tech`） |
|---|---|---|---|
| 短名 | 灰堆旗 / 血纹 | 红十字通道 | 协议部队 / 掩体卫队 |
| 地盘 | 灰堆、森林路障 | 毒谷摊位、补给通道 | 掩体、裂谷、税卡 |
| 枪感 | 霰弹、土制炸药、轻机枪 | 中火、烟雾、针剂、盾推 | 精确步枪、闪光、电子干扰 |
| 护甲 | 粗糙但厚 | 响应者背心 | 防暴 |
| 长处 | 破门、守口 | 救人、守点、护车 | 夜间、室内、断电前的精密战 |
| 短处 | 纪律差、复杂室内弱 | 缺重火硬刚堡垒 | 野外补给差；电站被拔则掉级 |

**对抗矩阵**（战役与活动）：

- 掠夺者 vs 响应者：破堡 / 护车（标准 5v5）；
- 掠夺者 vs 残存政府：抢税卡 / 抢阵列；
- 响应者 vs 残存政府：数据公开 vs 征收；
- 三派混战仅限活动，以免经济与爆点失衡。

# 第五章 · 核心规则（能打的那一层）

## 5.1 瓶盖与回合经济

- **瓶盖是唯一硬通货**。回合开始收入 = 上回合战绩 + 据点补给；胜 > 败 > 击杀。连败补偿叫「据点救济」（合约第五条的仲裁安抚金，连败递增防雪崩）。
- 击杀赏金按武器分档：弱武器高赏金，强武器低赏金——鼓励 eco 局。
- 阵亡掉落归胜方拾取变现（合约第三条）。
- **武器不跨图携带，跨回合携带。**
- **黑市局**：可用盖偷对面武器箱（高费高风险）。
- **区域垄断**（战役）：同区连胜后，该区地图购买折扣、额外烟雾或护甲。
- **动脉**：铁路开捷径；电站控灯；净水站控回血。

## 5.2 武器族（按地点解锁，避免通用现代枪皮）

| 族 | 来源（指回地标） | 职责 |
|---|---|---|
| 管枪 / 土制 | 废场、掠夺堡 | eco 局；高风险高回报 |
| 制式短点 | 毒谷枪铺 | 步枪位主流 |
| 精确 surplus | 旧军械库、掩体 | 狙击与中远 |
| 堡垒机枪 | 灰堆 | 守口 |
| 散弹 | 改装工坊、管道 | 室内 |
| 烟雾与燃烧 | 响应者 / 加油站 | 转点 |
| 闪光与干扰 | 裂谷 | 突入 |
| 针剂与抗辐 | 医疗链 | 生存 |

三档叙事：**土造档**（据点作坊，便宜粗糙）→ **战前档**（旧军械库，主流可靠）→ **派系档**（政府/虫洞科技，昂贵特色）。投掷物统一走土造叙事：燃烧瓶、酸瓶、钉管雷、信号棒。近战默认撬棍或消防斧，刀只在黑市出现。

## 5.3 生存规则

- 单回合死亡等待，经济保留；整图失败不抹战役声望。
- 户外辐射条；室内、掩体、防化服降低速率；抗辐剂是响应者特色买品。
- 毒雾、落水、低洼毒气走环境伤，护甲不能全免。
- 绿洲 / 安全区 / 掩体是吸气点；「无安全区」周连买枪廊也暴露。
- **个人生存资源遵循「氛围在、负担不在」**：辐射以盖革音效与屏幕噪点表现（竞技模式不管理口粮伤病）；回合间隙的啃罐头、缠绷带只是动画与语音彩蛋。

## 5.4 战斗规则

目标手感：CS 1.6 式短回合，不引入大逃杀缩圈——衰减压力用辐射与风暴回合表达。

- 人数：5v5 标准；3v3 巷战；2v2 枪铺。回合约 1:45，先到 8 或 16 胜。
- 移动有惯性；疾跑有声；蹲跳惩罚准星。爆头高倍；护甲减弹片与躯干。
- 友伤默认开；响应者局可关，作为「仁心规则」。

**标准模式**

| 模式 | 世界理由 | 胜负 |
|---|---|---|
| 井控（爆破） | 阿尔法/布拉沃安放井控模块，查理确认 | 守到起爆，或拆除 / 歼灭 |
| 通道（人质） | 隔离区或掩体救人（玛拉·凯恩的合约） | 护送出门，或歼灭营救方 |
| 护车 | 医疗车队 / 商队 | 车抵达补给点 |
| 夺旗 | 灰堆旗杆 / 响应者通道权 | 拔旗回到出生闸 |
| 猎头 | 赏金站通缉令 | 击杀目标或目标存活到时限 |
| 死斗 | 爆心余波 / 无法无天周 | 击杀数 |
| 衰减生存 | 尸潮 + 尘暴 | 先抗波次，再互抢撤离点 |
| 突围 | 出口-7 | 时限内冲出闸机 |

**战术卡**（由桌游道具卡逐张翻译，黑市淘，手牌上限 4）：

| 桌游原卡 | 战线版本 |
|---|---|
| 急行军 | 下一次转点短时移速（非无限跑） |
| 通行证 | 隔离区开门 / 忽略一次税卡 |
| 特赦令 | 取消因误伤中立导致的赏金 |
| 护盾 | 抵消下一次爆炸或一次税 |
| 掠夺卡 | 从经济第一的对手账户抢 100 盖 |
| 购地卡 | 模式限定：立即占领脚下无主点 |
| 拆迁令 | 破坏一处已建地堡/门 |
| 遥控骰 | 指定进攻方向提示（不做掷骰） |
| 换地卡 | 交换两个已控点 |
| 均富卡 | 全场经济平均，仅娱乐局 |

**地图硬规则**

1. 标准爆破图必须有两条以上进攻路 + 一条险路（管道、天桥、地沟）；
2. 爆点必须能用世界语言读懂：井盖、月台、保险柜、滤池控制室——禁止无故平地箱；
3. 中立 NPC 受击改声望，不改弹道公式；
4. 辐射区必须有盖革声；
5. 虫洞传送必须有 1.5s 可见预兆；
6. 新地图优先复用第三章地标，再动扩展槽；
7. 密钥乱序无效——UI 与关卡脚本都必须拒绝查理先于阿尔法；
8. 每张地图加载页显示「核心事件背景」（如「本图基于 AB 28 东栅失守」），让玩家在开火前知道为什么而战。

# 第六章 · 叙事如何支撑玩法

> 本章回答：为什么这套世界观**必须**长在类 CS 的回合制小队射击上。

| 玩法体验 | 世界观支撑 |
|---|---|
| 为什么是 5v5 限时定点冲突 | 冲突合约第一、二条：小队、限时、公示胜负条件（1.2） |
| 为什么回合内死了不复活 | 「仲裁者只统计站到最后的人」——合约减员（1.2） |
| 为什么回合间买枪、经济循环 | 整备阶段 + 仲裁预付款 + 合约第三条的装备归属（5.1） |
| 为什么双方要换边 | 合约规定系列赛攻防互换：「光会守的人不配赢」（2.1） |
| 为什么玩家会遵守规则 | 毁约者上「见字即杀」的黑市通缉榜（1.4） |
| 为什么爆破模式叫井控 | 守誓协议仍在等握手；安放的是让它重新握手的模块（3.4） |
| 为什么地图都是「有名字的地方」 | 每张图指回桌游 44 格地标——大亨的地契就是你的战场（约法 1） |
| 为什么有风暴回合与辐射区 | 衰减季：与桌游的每回合扣盖是同一场尘暴（1.3） |
| 为什么中立 NPC 打不得 | 手册派的人情网络：误伤锁针剂、拉仇恨——道德不改弹道，改的是谁帮你（1.5） |
| 为什么周轮换规则每周变 | 突变因子 =「今年环线又疯了」的战地版本（5.5） |

**设计纪律**：每个新模式立项先答两问——它对应哪一条合约条款或哪一段焚年历史？它的胜负条件能否用世界语言（井盖、月台、通缉令）读懂？答不出的模式不进匹配池。

# 第七章 · 两作联动与扩展空间

## 7.1 同一世界，两个阶级

- **《废土大亨》**：地契寡头的视角——**用瓶盖买别人的命**；
- **《废土战线》**：合约兵的视角——**用命换瓶盖**。

共享：焚年 32 时间线、五区、三派 id、地标（三井 / 国会掩体 / 矿洞 / 电台阵列……）、瓶盖、道德结局名、灰日三幕过场、十四条任务链的故事核，以及最大悬念——**三井密钥与失联的确认官**。

## 7.2 边界表

| 共享 | 不共享 |
|---|---|
| 五区地名、三派 id、三井顺序 | 掷骰、地产升级等级、手牌 UI |
| 瓶盖、道德作为战役标签 | 租金公式、垄断结算 |
| 灰日三幕过场文案 | 44 格路径与洗牌 |
| 任务链的故事核 | 事件卡二选一 UI |
| 终局名称 | 「绝对胜利核平棋盘」的结算代码 |

FPS 失败不得回写桌游存档；桌游核弹结局可作为本作战役的「核爆余烬」开局修饰（某地图出现蘑菇云余烬贴图、辐射事件频率上升），需玩家明确导入。

## 7.3 联动钩子（预留）

- 战线玩家打的每一张爆破图（格拉夫顿、莫诺加……），其地契可能正握在某位大亨玩家手里——跨作叙事彩蛋的天然接口；
- 大亨侧的突变因子与战线侧的周轮换共用命名与世界解释，可做同步「异常季」活动；
- 道德值 ↔ 派系声望在两作间互为背景变量（只作标签，不作数值同步）。

## 7.4 战线侧扩展预留

- **新模式**：合约系统天然支持周常轮换（仲裁者每周公示高价值合约 = 轮换地图/模式池）；
- **新势力入场**：战争机器残部可升格为 PVE 阵营；东边商队母邦是「盆地之外」的扩张阀门；
- **天气与时段变体**：沙尘暴（能见度）、酸雨（音效遮蔽脚步）、暮色（光照）——同一地图 × 三种天气 = 三种战术体验；
- **前传战役**：AB -18 至 AB 0 的「确认官悬案」——扮演灰日当天的井控警卫，打一场注定失败的战役；
- **UGC 地图**：允许社区基于第三章「地点清单」申请创作，锚点必须指回已有地标。
