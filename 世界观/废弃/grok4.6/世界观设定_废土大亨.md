**一句话**：大熄灯之后的阿帕拉契亚不是坟场，而是一座仍在运转的环形账本——五区咬合、三派分食、三井未眠。谁握住瓶盖、铁轨、净水和密钥，谁就握住废土的咽喉。

**设计原则**

1. **棋盘即世界。** 44 格环形路径是盆地文明的压缩模型，不是换皮装饰。
2. **圈地即生存。** 冲突主要通过占领、租金、税卡、事件抉择完成，不通过射击。
3. **三派不对等。** 掠夺者、响应者、残存政府没有正义方；声望可负可正。
4. **密钥即终局。** 阿尔法 → 布拉沃 → 查理对齐后发射，核平棋盘，绝对胜利。
5. **道德改命运，不改租金公式。** 抉择累积成章节旁白、NPC 态度与通关结局。

## 第一章　世界背景

### 1.1 这片土地叫什么

官方残档仍写着「阿帕拉契亚行政区」。幸存者口头只叫 **废土**，电台报时叫 **棋盘**——因为所有还能走的路，最终都绕回同一圈：从避难所出口出发，穿过森林、毒谷、灰堆、裂谷、沼泽，再被铁轨和税卡拧回起点。

世界不是无限开放沙盒。它是一座被辐射尘、塌方和派系路障 **圈死的盆地文明**。盆地外是更高的盖革读数、更密的尸潮走廊，以及已经没有回声的旧国边境。盆地内才有灯、水、枪和名字。

盆地中央有一块玻璃化的焦土。棋盘上称作靶场，《幸存者手册》称作 **爆心区**。风从那里刮出来，带着旧日核爆的热尘。三座导弹井的默认落点，至今锁死在这块焦土上。

### 1.2 大熄灯以前

灰日之前，阿帕拉契亚是旧世界的能源、军工与生物实验走廊：

- 浅层煤矿、深井铀矿与管道网把森林区拧成工业肺叶。
- 毒谷区堆满化工与军火转口，黑市的前身就是合法的「战时配给交易所」。
- 灰堆区是露天矿与焦化带，烟雾常年压着河谷。
- 裂谷区承接数据、量子通讯与自动化防务——三井发射协议的大脑长在这里。
- 沼泽区被划成隔离试验场：培养池、样本库、蔓越莓基因场，名义上是农业复兴，实际上是生物保险柜。

旧国会在裂谷边缘修了一座 **国会掩体**，对外称民防示范工程，对内是战时指挥备份。阿尔法、布拉沃、查理三座导弹井沿铁路线埋入山体，由「阿帕拉契亚自动化发射系统」互相握手。系统设计者相信：只要三枚密钥对齐，人类就仍握有最后的否决权。

他们错了。系统没有否决权，只有执行权。

### 1.3 灰日（焚年 0）

没有人再准确记得第一枚弹是谁先按的。废土电台把那一天叫 **灰日**，手册把那年定为 **焚年 0**。

已知残片：

1. 战略网络先于城市死去。电磁脉冲把屏幕打成雪花，货运机器人在半空失去航线。
2. 自动化发射系统完成一次「靶场校准」——默认落点：盆地中央集结点。
3. 弹头离井。中央焦土生成；五区未被一次性抹平，却被冲击波、沉降与设施连环崩溃撕开。
4. 民防避难所 **出口-7** 封门。国会掩体转入无菌循环。隔离区从防疫营地变成永久拘留场。
5. 活着的人开始用瓶盖记账——旧钞烧完以后，瓶盖是少数还能被所有人认作「真的」的金属。

灰日不是世界的结束，是 **旧秩序把钥匙留在井里、把人关在门后** 的那一天。

### 1.4 避难所年代（焚年 0–25）

出口-7 按民防条例封闭二十五年。门内有定额罐头、循环水，以及一部越改越像圣经的《幸存者手册》。门外，五区按各自的废墟逻辑重新长出血肉：

- 森林区的管道和天桥变成拾荒者的骨架城市。
- 毒谷区的配给所退化成摊位、枪铺和情报贩子。
- 灰堆区的矿工武装化，成为最早的掠夺堡。
- 裂谷区的数据塔与电台阵列仍间歇自检，像一具不肯断气的机器尸体。
- 沼泽区的培养池外溢，雾把公路吞成走廊。

响应者从旧急救志愿网重生，专门抢回伤员和干净水。掠夺者在灰堆完成第一次「军阀联合」。残存政府缩在国会掩体与裂谷设施里，用无人机采样、用税卡证明自己还是「国家」。

### 1.5 开门与第七日（焚年 25）

铁门开启后的第七天，是闯关叙事的元年，也是对局默认的「当代」。

门开不是解放。隔离区警报仍在远处嗡鸣；半箱瓶盖是一个人在废土上的全部国籍。营地的人站在出口两侧打量每一个踏出铁门的人：**独狼，还是领路人。**

从此进入 **大亨时代**——不是因为有人想当国王，而是因为瓶盖、地产、铁路和设施第一次重新变成可垄断的权力。谁先在某个颜色的区域说了算，谁就能收租、设卡、发通行证。

### 1.6 当代废土的运转法则

当代（焚年 25–32）有三条比法律更硬的法则：

1. **圈地即生存。** 无主地产谁先插旗谁收租。垄断一组区域后租金翻倍——整条街只认一家的旗。
2. **动脉决定生死。** 阿尔法 / 布拉沃 / 查理三哨是铁轨枢纽，裂谷电站与沼泽净水站是水电咽喉。掐住其中两条，就能让对面营地断粮断电。
3. **密钥仍在握手。** 发射系统从未真正下线。它在频段里循环自检，等有人把三枚井控密钥重新对齐。发射后没有谈判，只有蘑菇云与绝对胜利。

气候上，盆地已进入 **废土衰减期**：辐射尘暴从间歇变为季节性常驻。闯关后期每过一轮，土地就从账本上刮走一层。

### 1.7 人如何理解这世界

废土没有统一宗教，但有四套互相打架的解释：

| 解释 | 持有者 | 核心信条 |
|---|---|---|
| 手册派 | 响应者、多数营地 | 前人笔记比口号可靠；分享净水与药品是续命，不是慈善 |
| 井口派 | 拾荒客、部分军阀 | 三井是旧神的喉舌；握密钥者即握末日 |
| 协议派 | 残存政府 | 国家从未死亡，只是改在掩体办公；税与采样都是「恢复秩序」 |
| 虫洞派 | 遗迹猎人 | 棋盘中央的蓝光不是故障，是旧世界留给下一纪元的门 |

这些解释不改租金数字，但决定事件卡里谁肯开门、谁肯分药、谁肯把晶体上缴。

## 第二章　地点

每个地点给出：**在世界里是什么 / 在棋盘上怎么结算**。格子顺序每局洗牌（据点固定第 0 格）——路在变，地方还在。

### 2.1 五区

颜色不是行政区划，是物资生态与收租风格。

| 区 | 棋盘组 | 气质 | 主导资源 | 可购地产 |
|---|---|---|---|---|
| 森林区 | `rust` | 锈、木、断桥、浅层工业 | 废铁、燃油、掩体木材 | 摩根镇废场、森林断墙、锈蚀管道、断裂天桥、旧警备所、森林加油站 |
| 毒谷区 | `market` | 摊、枪、情报、改装 | 弹药、药品、黑市货 | 响应者摊位、毒谷枪铺、格拉夫顿补给、改装工坊、毒谷情报商 |
| 灰堆区 | `gang` | 堡垒、毒巢、军阀 | 炸药、保护费、人口 | 灰堆掠夺堡、掠夺者军阀、灰堆毒巢 |
| 裂谷区 | `tech` | 塔、阵列、量子站 | 电力、数据、密钥碎片 | 裂谷数据塔、隔离电台阵列、裂谷量子站 |
| 沼泽区 | `bio` | 雾、培养池、基因场 | 净水、血清、变异样本 | 裂隙培养池、沼泽样本库、蔓越莓基因场 |

同色全控且未抵押 = **垄断**，该组租金 ×2。地产可升两级（地堡化），升级前须先垄断。可半价抵押、约 55% 赎回。

### 2.2 系统枢纽（非地产格）

#### 避难所出口（`start`）〔据点〕

出口-7 的外闸。铁门后是定额秩序，门前是废土。出生点；经过发放据点补给（标准约 200 盖，难度与突变可改）。

#### 隔离区（`quarantine`）〔禁区〕

灰日后的永久拘留场。踩上此格、或连续三次掷出双数，即被关入。出狱：再掷双数、交 50 盖，或出示通行证。「无法无天」突变下隔离失效——狱卒被买通，或尸潮冲垮铁网。

里面关的不只是病人，还有缴不起税的人、被赏金站点名的人。

#### 安全地带（`safe`）〔休整〕

盖革读数稳定、派系默契停火的口袋。默认只休整；「免费停车彩金」下，税与租金会淤在这里被人卷走。「无安全区」突变时连这里也要收占用费。

#### 事件格（`event`）

废土电台、幸存者手册、派系密使、遗迹猎人四座牌堆的交汇点。不是空地，是信息战场。

#### 税收格（`tax`）

残存政府仍在收的过路税：50 / 75 / 100 盖三档。护盾可免。「高税时代」下翻倍。

#### 黑市（`blackmarket`）

灰色动脉的心室。可花 80 盖偷袭抢下一块未抵押敌产（等级清零）、搜出狱卡，或花 120 盖淘道具卡（手牌上限 4）。密钥偶尔夹在赃物堆底部。

#### 赏金站（`bounty`）

废土的通缉墙。净身家最高者是头号目标：本人踩此格领 100 盖；其他人踩此格向其缴纳最多 60 盖。

#### 绿洲（`oasis`）

未被污染的温泉与浅泉。补给微薄（+25 盖），衰减季里比枪更贵。

#### 虫洞（`wormhole`）〔异常〕

蓝光裂口。踏入传到随机格；「虫洞紊乱」下距离加倍。遗迹猎人相信另一端有旧世界晶体。

#### 莫诺加矿洞（`radiation`）〔辐射禁区〕

浅层矿脉与深层铅封罐并存。深采 80 盖换 150 盖；浅采 40 盖换 70 盖，但道德 −1。铅封罐与金属碎片是密钥常见来源。

#### 国会掩体（`bunker`）〔政治飞地〕

无菌空气、厚门、旧档案。休整 +35 盖且道德 +1，或就地免费加固一处地产。

### 2.3 三哨与两座设施〔动脉〕

| 名称 | 类型 | 世界职能 | 棋盘结算 |
|---|---|---|---|
| 阿尔法哨 | 铁路 | 西缘井口与月台 | 1/2/3 条铁路过路费 25 / 50 / 100 |
| 布拉沃哨 | 铁路 | 中段转运与应答天线 | 同上 |
| 查理哨 | 铁路 | 东缘；默认靶场校准端 | 同上 |
| 裂谷电站 | 设施 | 盆地电力咽喉 | 1 座收租 ×4 骰点，2 座 ×10 |
| 沼泽净水站 | 设施 | 盆地饮用水咽喉 | 同上 |

掐住两条铁路或两座设施，等于掐住废土的气管。闯关第三章「黑市暗流」的目标由此而来。

### 2.4 爆心区〔绝对禁区〕

棋盘中央不是可走格，却是世界的胃。查理井的默认靶标锁在这里。发射后蘑菇云在中央升起，对局以绝对胜利结束。

### 2.5 地点与事件钩

| 区 | 地标 | 常挂钩的故事 |
|---|---|---|
| 森林 | 废场、断墙、天桥、加油站 | 货运机器人坠毁、诱杀陷阱、沙暴 |

### 3.2 灰日三幕

与核弹过场同构，便于语音与分镜复用：

1. **战略警报** — 三座导弹井同时上电，扩散协议解锁。
2. **密钥对齐** — 阿尔法 · 布拉沃 · 查理，发射授权确认。
3. **弹头离井** — 落点锁定盆地中央，无可拦截。

发射系统没有道德，只认密钥。有人再次集齐三钥时，同一套分镜会重演。

### 3.3 六章当代史（闯关）

闯关六章是一个幸存者的账本，也是盆地当代史的缩写。每章开场按进入时的道德值分仁心 / 标准 / 冷面三档旁白。

| 章 | 名称 | 历史含量 | 目标要点 |
|---|---|---|---|
| 一 | 据点求生 | 开门后站稳 | 瓶盖 ≥1200 / 5 块地产 / 道德 ≥3 |
| 二 | 垄断一方 | 颜色区第一次出现「老板」 | 任意一组垄断 / 净身家 ≥2600 / 道德 ≥5 |
| 三 | 黑市暗流 | 铁路与设施成为动脉 | 2 条铁路或 2 座设施 / 净身家 ≥3500 / 道德 ≥6 |
| 四 | 废土衰减 | 尘暴不再间歇 | 8 块地产 / 净身家 ≥4200 / 道德 ≥7；每回合 −8 盖 |
| 五 | 废土传说 | 名字开始被写进手册 | 12 块地产 / 净身家 ≥5000 / 道德 ≥8；每回合 −12 盖 |
| 六 | 废土归属 | 家园或新军阀 | 16 块地产 / 净身家 ≥6500 / 道德 ≥10；每回合 −15 盖 |

合作闯关：瓶盖与地产取双方总和，道德取人类决策者。

| 间谍 | 线人 → 补给时刻表 → 双面或证人 | 接赃、告发、站队 |
| 叛变 | 投名状 → 复仇或调停 | 废土上没有两面讨好 |
| 防空洞 / AI | 旧档案 → 终端 AI → 武器库坐标 | 交流或拆卖；潜入或放弃 |
| 核弹 | 自检 → 布拉沃应答 → 查理校准 | 录密钥或掐断信号 |
| 货运坠毁 | 拆零件或上报坐标 | 独吞电容，或留给响应者 |
| 反应堆 / 爆心 | 抢修或撤离；搜刮或绕开 | 辐射钱与肺 |

四座牌堆：废土电台（坏，30%）、幸存者手册（好/中性，30%）、派系密使（声望，20%）、遗迹猎人（探索，20%）。

### 3.5 核军备从未结束

密钥出现的位置，是世界仍在漏电的证据：

- 莫诺加深井铅封罐、浅层金属碎片
- 黑市赃物堆、旧货箱夹层
- 隔离电台阵列废弃产线；若已占领该地，则来自机密保险柜
- 手册夹层的加密页

顺序固定：**阿尔法 → 布拉沃 → 查理**。握手协议拒绝乱序。「核军备竞赛」突变下掉落率翻倍，AI 集齐后会真的发射。

### 3.6 遗产与叙事传承

对玩家是跨局成长，对世界是上一代传说改写下一代开局。

| 上局结局 | 世界状态 | 下局开局 |
|---|---|---|
| 暴君 | 名字成禁忌 | 坏事件↑，掠夺者/响应者声望惩罚 |
| 仁心领袖 / 家园建造者 | 手册首页有你的名字 | 好事件↑，起始道德 |
| 核弹 | 第二朵蘑菇云的余烬 | 辐射泄漏，坏事件↑ |
| 普通幸存 | 多活了一季 | 起始盖与通行证 |
| 合作通关 | 战友还在 | AI 更让拍卖，好事件微增 |

遗产点来自存活回合、章节、道德；核弹结局额外 +100。可永久兑换起始盖、据点补给、道德起步、出狱卡、突变重抽、开局手牌。

### 3.7 终局（互斥）

通关第六章后按最终道德判定；核弹线可在任何模式抢先结束对局。

1. **家园建造者**（道德 ≥14）：围墙有名字，孩子在庇护下长大。
2. **仁心领袖**（≥10）：残酷少了几分。
3. **废土传说**（≥8）：名字进手册，秩序未定。
4. **冷面幸存者**（≥4）：手册只写「实用」。
5. **暴君**（<4）：营地低头，有人叫你新军阀。
6. **核平**：棋盘中央再次玻璃化。绝对胜利。下一季辐射更频。

## 第四章　核心设定

### 4.1 势力阵营

存档 id 保持 `eagle` / `survivor` / `tech`，显示名：掠夺者 / 响应者 / 残存政府。

#### 掠夺者（`eagle`）

- **地盘**：灰堆为主，森林路障为辅。
- **组织**：军阀联合，不是军队。信使递带血纹徽章，接活才算自己人。
- **哲学**：保护费比税诚实；旗在，秩序就在。
- **任务口吻**：运货、清对头据点、对响应者纳投名状。

#### 响应者（`survivor`）

- **地盘**：毒谷摊位、补给通道、部分森林营地。
- **组织**：志愿网。没有统一司令，有公开的红十字识别。
- **哲学**：通道要开，药要分，活泉不能进私人账本。
- **任务口吻**：开放伤员通道、共享水源、公开基因数据。

#### 残存政府（`tech`）

- **地盘**：国会掩体、裂谷设施、税卡、电台阵列。
- **组织**：科层残留 + 无人机。自称国家，实际是飞地。
- **哲学**：采样、课税、密钥研究都是「恢复秩序」。可与黑市洗白合作。
- **任务口吻**：辐射采样、收购晶体与基因档案、证人保护。

三派都不是天然好人。响应者收费通行会掉道德；政府可以买黑货；掠夺者可以劝降收编。声望只改密使任务与部分选项，不改骰子。

中立角色：黑市账房、遗迹猎人、东边商队、尸潮、出口-7 门卫、自动化井控、旧终端 AI。他们出现在事件里，不是第四可玩阵营。

### 4.2 资源体系

#### 硬通货：瓶盖

开局约 1500 盖（简单 1800 / 噩梦 1100）。据点补给约 200 盖 / 圈。买地、交租、缴税、淘卡、深采、贿赂，全部走瓶盖。不引入第二货币。

#### 地产、铁路、设施

见第二章。净身家 = 现金 + 未抵押地产价格 + 升级投入。破产时地产归债主或银行；通行证可被债主接收。

#### 道具卡

黑市 120 盖随机淘，手牌上限 4。稀有度 common / rare / epic。

| 卡 | 效果 |
|---|---|
| 急行军 | 本回合掷骰 +2（掷骰前） |
| 通行证 | 获得 1 张出狱卡 |
| 特赦令 | 道德 +2 |
| 护盾 | 下次被收租或缴税全额免除 |
| 掠夺卡 | 从最富对手处抢 100 盖 |
| 购地卡 | 免费获得脚下无主地块 |
| 拆迁令 | 对手一块地降 1 级 |
| 遥控骰 | 指定下一次掷骰点数和 |
| 换地卡 | 与对手各选一块地对换 |
| 均富卡 | 全体存活玩家现金平均 |

#### 密钥

不是货币，是世界级胜负手。三枚齐且未破产即可发射。

### 4.3 生存规则

- **出局**：现金跌破 0 即破产。对抗模式最后存活者胜；闯关中途破产即失败。
- **隔离**：暂停键。通行证是稀缺人权。
- **辐射与衰减**：矿洞、尘暴、衰减章每回合刮盖。
- **道德**：救人、公开、分享上升；抛弃、独占、洗劫下降。特赦令 +2，浅采矿 −1。
- **安全 / 绿洲 / 掩体**：三处吸气点。衰减季里连停火都开始标价。

难度档只改开局盖、补给、税率与 AI 激进度，不改世界地理。

### 4.4 冲突规则（桌游）

废土大亨的「战斗」走账本与抉择：

- 踩敌产地缴租；垄断与升级放大伤害。
- 黑市偷袭可花 80 盖抢地并抹平等级。
- 赏金站让首富成为公敌。
- 事件选项是战斗的叙事替代：死守、突围、劝降、清场。
- 连续三双数 = 战术冒进，关进隔离区。
- 护盾抵一次租或税。
- 核弹是唯一真正开火，一经开火即终局。

回合上限：对抗 1500，闯关 1000。

### 4.5 规则突变

遗产模式每局抽 3 个因子。世界观把它们写成季节性疾病。

| 突变 | 世界解释 | 规则 |
|---|---|---|
| 双倍租金 | 保护费通胀 | 租金 ×2 |
| 无法无天 | 隔离网塌了 | 无法关押 |
| 尸潮频发 | 东栅再次失守 | 坏事件 +30% |
| 辐射泄漏 | 冷却塔破裂 | 每回合额外 −5 盖 |
| 富饶开局 | 空投季 | 起始 +500 盖 |
| 无安全区 | 停火默契破裂 | 安全格失效 |
| 双倍补给 | 据点开仓 | 经过据点补给 ×2 |
| 地产泡沫 / 抄底 | 黑市定价紊乱 | 地价 +50% / −30% |
| 道德困境 | 粮荒 | 每回合道德 −1 |
| 虫洞紊乱 | 蓝光暴涨 | 传送距离 ×2 |

| 和平主义 | 临时停火令 | 无法收租，每回合 +20 盖 |

| 核军备竞赛 | 井口敏感 | 密钥掉落 ×2，AI 会发射 |

其余因子（废土银行、连锁垄断、地产维护费、均富协议、绝境狂奔、超频骰、免费停车彩金等）同 `js/mutators.js`。

### 4.6 四种游戏模式在世界里的含义

| 模式 | 世界读法 |
|---|---|
| 对抗 2–4 人 | 大亨时代的圈地战争，最后活账本胜 |
| 单人闯关 | 第七日之后一个幸存者的六章归属 |
| 合作闯关 | 两人共用一个营地账本，对抗衰减 |
| 遗产模式 | 上一代传说改写这一季的气候与人心 |

棋盘每局重排：沙暴、塌方、尸潮切断旧路、逼出新路。摩根镇仍是摩根镇，三井仍在原坐标。

### 4.7 约法

1. 五区名称与三派 id 不得无故更名，以免存档与语音包断裂。
2. 密钥必须按阿尔法 → 布拉沃 → 查理。
3. 瓶盖是唯一硬通货。
4. 核弹是绝对胜利，不是普通奖励。
5. 隔离区可以因突变失效，但不能从世界上删掉。
6. 三派都不是天然善恶。
7. 道德不直接改租金与骰子。
8. 新增格子先改 `tiles.json` 与本文第二章，再改规则代码。
9. 虫洞是异常，不是日常快捷旅行。
10. 射击玩法不写进本文，见 `世界观设定_FPS.md`。
