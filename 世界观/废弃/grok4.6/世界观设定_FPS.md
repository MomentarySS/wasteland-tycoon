# 废土战术射击（新项目）· 世界观设定

> 新 FPS 的设计圣经。手感目标：类 CS 1.6 的短回合、买枪、爆点、经济循环；外壳是阿帕拉契亚废土。  
> 世界与《废土大亨：末世大富翁》共享同一 IP。历史、地名、三派、三井以姊妹文档 [`世界观设定_废土大亨.md`](世界观设定_废土大亨.md) 为canon；本文只写 **能打的那一层**。  
> 产品暂名可改，下列地图代号、模式名与阵营短名落地前勿写进玩家可见 UI。

---

**一句话**：同一座盆地，同一套密钥，换成交火。五区是地图包，三派是可选队皮，三井是爆破点，瓶盖是回合经济。

**设计原则**

1. **地点先于枪皮。** 每张图必须能指回一个已有地标；不要先做无出处的沙漠盒子。
2. **两队对抗为默认。** 掠夺者 / 响应者 / 残存政府不对等，匹配只放两队；第三派当地图 NPC 或周轮换。
3. **密钥即炸弹。** 井控模块安在阿尔法 / 布拉沃，查理井做确认或最终点。顺序不可乱。
4. **瓶盖即经济。** 回合买枪，不引入金币。经济不可带入下一张地图，可带入下一回合。
5. **道德不改伤害表。** 声望只改开局条件、可购战术道具、中立区态度与战役结局。

## 第一章　世界背景（作战简报）

### 1.1 战场是哪里

阿帕拉契亚盆地在灰日（焚年 0）被中央核爆撕开，又在焚年 25 出口-7 开门后重新变成可争夺的环形领地。到焚年 32——本作默认「现在」——五区咬合、三派分食、三井未眠。

作战人员不是从天而降的特种部队。他们是：

- 灰堆旗下的收债队与破堡手；
- 响应者通道上的护车员与急救射手；
- 残存政府从国会掩体派出来的协议部队。

盆地外没有可玩的前线。更高辐射、更密尸潮、已死的旧国边境，只作为地图边缘的不可进入区与天空盒。灯、水、枪和名字都在圈内。

盆地中央的 **爆心区** 是玻璃化焦土，查理井默认靶标锁在那里。它不是常规出生图，是终局舞台。

完整前史（灰日前军工走廊、封门二十五年、第七日）见桌游设定第一章。FPS 只需要记住三句话：

1. 旧世界把最后的按钮交给了机器。
2. 机器在灰日执行了一次靶场校准。
3. 系统从未下线，仍在等三枚密钥握手。

### 1.2 当代三条作战法则

1. **控点即生存。** 垄断一条街 = 该区地图买枪折扣与额外烟雾/护甲。对应桌游的同色垄断。
2. **动脉决定转点。** 控阿尔法 / 布拉沃 / 查理哨打开铁轨捷径；控裂谷电站改灯光；控沼泽净水站给己方回血光环。
3. **井口仍在监听。** 集齐密钥可发起井控协议。起爆后没有加时谈判，只有撤离或与棋盘一同核平。

衰减季已经开始：辐射尘暴从间歇变为季节。对应规则是 **风暴回合**——视野缩短、户外持续掉血、室内与掩体升值。

### 1.3 四套解释，决定 NPC 开不开门

| 解释 | 谁信 | 对交火的影响 |
|---|---|---|
| 手册派 | 响应者、多数营地 | 中立摊主、伤员、商队；误伤会拉仇恨、锁针剂 |
| 井口派 | 拾荒客、部分军阀 | 更愿卖爆弹与扰射，更恨拆井的人 |
| 协议派 | 残存政府 | 税卡、无人机、掩体闸机认「证件」 |
| 虫洞派 | 遗迹猎人 | 异常回合的传送口由他们标记；无预兆瞬移禁止 |

这些解释不改爆头倍率。

## 第二章　地点（地图目录）

### 2.1 五区 = 五套关卡气质

| 区 | 来源组 | 气质 | 主导资源 | 交战 |
|---|---|---|---|---|
| 森林区 | rust | 锈、木、断桥 | 废铁、燃油、木掩体 | 中远距离、天桥与管道高低差 |
| 毒谷区 | market | 摊、枪、情报 | 弹药、药品、黑市货 | 短兵巷战、室内外切换 |
| 灰堆区 | gang | 堡垒、毒巢 | 炸药、机枪口 | 攻坚与巷口封锁 |
| 裂谷区 | tech | 塔、阵列、量子 | 电力、数据、密钥 | 垂直战场、电子干扰 |
| 沼泽区 | bio | 雾、培养池 | 净水、血清 | 低能见度、毒雾与窄堤 |

五区之间没有国境，只有税卡、路障、尸潮走廊和辐射斑。商队按手册周期从东边进；掠夺者按暗号在补给点设伏；政府无人机在头顶采样。

### 2.8 三哨：爆破点原教旨

| 哨 | 意象 | 职能 |
|---|---|---|
| 阿尔法哨 | 西缘井口与月台 | 爆破点 A；井盖可开关 |
| 布拉沃哨 | 中段转运与应答天线 | 爆破点 B / 中路枢纽 |
| 查理哨 | 东缘，靶场校准端 | 点 C 或最终确认井；与爆心区视野相连 |

## 第三章　事件（战役与行动）

焚年纪年与桌游相同。FPS 把历史写成可打的行动，而不是事件卡。

### 3.1 时间锚点（作战用）

```
AB  0     灰日。中央靶场核平。三井完成一次校准
AB  9     灰堆旗升起——掠夺堡可打
AB 12     第一份税令——税卡作为地图机关出现
AB 21     活泉争夺——净水站占点有历史
AB 24     发射系统周期性自检——密钥链可做
AB 25.D7  第七日开门——教学突围
AB 28     东栅被大型尸潮撞开——生存图
AB 30     虫洞可见化——异常回合
AB 32     当代。衰减季。默认匹配时间
```

灰日三幕直接复用为核弹终局过场：战略警报 → 密钥对齐 → 弹头离井。

### 3.2 战役六幕

与桌游闯关同名，解锁地图而不是章节目标数字。

| 幕 | 名称 | 解锁 | 胜负读法 |
|---|---|---|---|
| 一 | 据点求生 | 出口 → 废场 → 旧警备所 | 站住出生区 |
| 二 | 垄断一方 | 同色两图连胜 | 赢者获该区买枪折扣 |
| 三 | 黑市暗流 | 三哨 + 水电设施 | 控动脉 |
| 四 | 废土衰减 | 全图辐射规则 | 风暴回合常开 |
| 五 | 废土传说 | 密钥链任务 | 开始井控 |
| 六 | 废土归属 | 终局三选一 | 守家 / 称王 / 发射 |

道德三档只改世界怎么看你：仁心则 NPC 开门、商队降价、响应者给烟幕与针剂；冷面则黑市更便宜、中立区敌对、开局可能被追杀。不改弹道。

### 3.3 任务链 → 行动目标

| 链 | 对局目标 |
|---|---|
| 掠夺者 | 破伏击 / 守桥 / 劝降或击溃 |
| 医疗 | 护车 / 抢药 / 营地防守 |
| 水源 | 守泉或夺泉 |
| 尸潮 | PvE 波次；最后一波可插入敌队 |
| 虫洞 | 携带晶体撤离 |
| 手册地图 | 搜刮；可留物资给下一回合随机玩家 |
| 科技 | 抢数据盘；公开则全员解锁医疗装备 |
| 商队 | 护送或截击 |
| 黑市帝国 | 控制黑市点位 |
| 间谍 | 潜伏：队友中有内奸规则变体 |
| 叛变 | 中途阵营转换 |
| 防空洞 / AI | 潜入掠夺者库房 |
| 核弹 | 按序启动三井 |
| 货运坠毁 | 抢空投 |
| 反应堆 / 爆心 | 高辐射限时 |

## 第四章　核心设定（能打的规则）

### 4.1 阵营

存档 id 与桌游一致：`eagle` / `survivor` / `tech`。

|  | 掠夺者 | 响应者 | 残存政府 |
|---|---|---|---|
| 短名 | 灰堆旗 / 血纹 | 响应者 / 红十字通道 | 协议部队 / 掩体卫队 |
| 地盘 | 灰堆、森林路障 | 毒谷摊位、补给通道 | 掩体、裂谷、税卡 |
| 枪感 | 霰弹、土制炸药、轻机枪守口 | 中火、烟雾、针剂、盾式推进 | 精确步枪、闪光、电子干扰 |
| 护甲 | 粗糙但厚 | 响应者背心 | 防暴 |
| 长处 | 破门、守口 | 救人、守点、护车 | 夜间、室内、断电前的精密战 |
| 短处 | 纪律差、复杂室内弱 | 缺重火硬刚堡垒 | 野外补给差；电站被拔则掉级 |

**对抗矩阵（匹配默认两队）**

- 掠夺者 vs 响应者：破堡 / 护车（标准 5v5）
- 掠夺者 vs 残存政府：抢税卡 / 抢阵列
- 响应者 vs 残存政府：数据公开 vs 征收
- 三人混战仅限活动，以免经济与爆点失衡

中立：黑市商人、遗迹猎人、东边商队、尸潮、门卫、井控系统、旧终端 AI。商人受击不改即时伤害公式以外的数值，但本回合声望下降。

### 4.2 资源与回合经济

- **瓶盖**：唯一硬通货。回合开始 = 上回合战绩 + 据点补给。胜 > 败 > 击杀。连败补偿叫「据点救济」。
- **武器不跨图携带，跨回合携带。**
- **黑市局**：可用盖偷对面武器箱（高费高风险）。
- **区域垄断**（战役）：同区连胜后，该区地图购买折扣、额外烟雾或护甲。
- **动脉**：铁路开捷径；电站控灯；净水站控回血。
- **密钥**：战役条件。三枚齐可解锁井控终局。匹配爆破用的是「井控模块」，不是把密钥每回合掉地上。
- **战术卡**（由桌游道具卡翻译，手牌上限 4，黑市淘）：

| 原卡 | 射击 |
|---|---|
| 急行军 | 下一次转点短时移速（非无限跑） |
| 通行证 | 隔离区开门 / 忽略一次税卡 |
| 特赦令 | 取消因误伤中立导致的赏金 |
| 护盾 | 抵消下一次爆炸或一次税 |
| 掠夺卡 | 从经济第一的对手账户抢 100 盖 |
| 购地卡 | 模式限定：立即占领脚下无主点 |
| 拆迁令 | 破坏一处已建地堡/门 |
| 遥控骰 | 指定进攻方向提示（不做掷骰） |
| 换地卡 | 交换两个已控点 |
| 均富卡 | 全场经济平均，仅娱乐局 |

### 4.3 生存

- 单回合死亡等待，经济保留。
- 整图失败不抹战役声望，衰减季仍扣盖。
- 户外辐射条；室内、掩体、防化服降低速率。抗辐剂是响应者特色买品。
- 毒雾、落水、低洼毒气走环境伤，护甲不能全免。
- 绿洲 / 安全区 / 掩体是吸气点；无安全区周连买枪廊也暴露。

### 4.4 战斗规则

目标手感：CS 1.6 式短回合，不引入大逃杀缩圈。衰减用辐射压户外。

**基础对局**

- 人数：5v5 标准；3v3 巷战；2v2 枪铺。
- 回合约 1:45。先到 8 或 16 胜。
- 移动有惯性；疾跑有声；蹲跳惩罚准星。
- 爆头高倍；护甲减弹片与躯干。
- 友伤默认开。响应者局可关，作为「仁心规则」。

**标准模式**

| 模式 | 世界理由 | 胜负 |
|---|---|---|
| 井控（爆破） | 阿尔法/布拉沃安放井控模块，查理确认 | 守到起爆，或拆除 / 歼灭 |
| 通道（人质） | 隔离区或掩体救人 | 护送出门，或歼灭营救方 |
| 护车 | 医疗车队 / 商队 | 车抵达补给点 |
| 夺旗 | 灰堆旗杆 / 响应者通道权 | 拔旗回到出生闸 |
| 猎头 | 赏金站 | 击杀目标或目标存活到时限 |
| 死斗 | 爆心余波 / 无法无天 | 击杀数 |
| 衰减生存 | 尸潮 + 尘暴 | 先抗波次，再互抢撤离点 |
| 突围 | 出口-7 | 时限内冲出闸机 |

**武器族（按地点解锁，避免通用现代枪皮肤）**

| 族 | 来源 | 职责 |
|---|---|---|
| 管枪 / 土制 | 废场、掠夺堡 | eco |
| 制式短点 | 毒谷枪铺 | 步枪位 |
| 精确 surplus | 军械库、掩体 | 狙击与中远 |
| 堡垒机枪 | 灰堆 | 守口 |
| 散弹 | 工坊、管道 | 室内 |
| 烟雾与燃烧 | 响应者 / 加油站 | 转点 |
| 闪光与干扰 | 裂谷 | 突入 |
| 针剂与抗辐 | 医疗链 | 生存 |

近战默认撬棍或消防斧。刀只在黑市出现。

**地图硬规则**

1. 标准爆破图必须有两条以上进攻路 + 一条险路（管道、天桥、地沟）。
2. 爆点必须能用世界语言读懂：井盖、月台、保险柜、滤池控制室，禁止无故平地箱。
3. 中立商人、伤员、摊主受击改声望，不改弹道公式。
4. 辐射区必须有盖革声。无声即无辐射。
5. 虫洞传送必须有 1.5s 可见预兆。
6. 新地图优先复用第二章地标，再动扩展槽。
7. 密钥乱序无效——UI 与关卡脚本都必须拒绝查理先于阿尔法。

### 4.7 约法

1. 不改五区名与三派 id。
2. 密钥只认阿尔法 → 布拉沃 → 查理。
3. 瓶盖是唯一硬通货。
4. 核平是终局，不是普通超杀奖励。
5. 匹配默认 2 队；第三派不当作平衡好的第三阵营塞进天梯。
6. 道德不加减射击伤害。
7. 每张图必须能指回地标或扩展槽。
8. 禁止无预兆传送。
9. 不把大富翁回合结构（掷骰、买地弹窗）搬进射击 HUD。
10. 世界 canon 冲突时，以 `世界观设定_废土大亨.md` 的历史为准，以本文的作战规则为准。
