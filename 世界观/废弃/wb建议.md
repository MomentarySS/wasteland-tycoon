## 0. 结论速览

| 维度 | GLM 5.3 | Grok 4.6 | MiniMax |
|---|---|---|---|
| **设定完整度** | 中高（背景/历史/地点/派系/道德全覆盖，缺机制层世界观化） | **高**（唯一做到"世界观↔机制"逐格双轨） | 高（十章+两附录，产品手册级框架） |
| **逻辑一致性** | 高（"地契大爆炸"因果链最完整） | 高（盆地设定自洽回答"为何是环形棋盘"） | 中（137 年时间线与开局叙事错位） |
| **与玩法契合度** | 中高（两处硬伤：派系名、纪年） | **最高**（密钥来源/顺序、第七日文本均与代码咬合） | 中（对得多、错得也多，存在编造条目） |
| **文学感染力** | **最高**（谚语、黑话、冷幽默成体系） | 中（准确但干） | 低（像维基不像故事） |
| **数据忠实度** | 中 | **最高** | 中高 |
| **可维护性** | 中 | 高（"约法"十条） | **最高**（维护规约+对照表） |

**一句话结论**：
- **GLM 是最好的"故事"**——把大富翁玩法翻译成废土社会史，"为什么收租、为什么掷骰、为什么破产"全部有世界观答案；
- **Grok 是最好的"正典"**——数据忠实度第一，且与已上线文本（"第七日"章节旁白）互相咬合；
- **MiniMax 是最好的"手册"**——框架最全、工程意识最强，但错误条目也最多，需修订后方可引用。

**融合策略：以 Grok 为骨架（正典基准），嫁接 GLM 的叙事引擎（地契大爆炸 + 文学资产），套用 MiniMax 的文档工程（对照表 + 维护规约），并按本文第 4 章核查结果修正错误。**

## 2. 逐份分析

### 2.1 GLM 5.3《世界观设定_废土大亨》

**设定完整度：中高**
- 覆盖：世界背景、44 地契逐格故事、大事年表、三大派系 + 四个中立势力、四牌堆、道德值、遗产/叙事传承、六章闯关、两作联动。主线要素无缺。
- 缺失：道具卡（10 张）无世界观化；25 个突变因子只在 4.5 节一笔带过；四种游戏模式没有"世界读法"；无任何数据对照表或维护规约。

**逻辑一致性：高（三份中因果链最漂亮）**
- 核心亮点是"地契大爆炸"：打仗打到破产（纪元 38 瓶盖战争）→ 银行与黑市推动产权化（纪元 41）→ 大亨时代（纪元 43）。这一段把"为什么废土上有人收租、为什么垄断一个区就能定价、为什么破产拍卖"讲成了经济史，是三份文档里对大富翁玩法**最强的动机叙事**。
- "骰子：废土之神"一节正面回答了"为什么走路靠掷骰"——三份中唯一给骰子做世界观处理的。
- "废土衰减"（四至六章每回合扣钱）被解释为"地契红利期结束"——把后期难度曲线写进了时代背景，这个处理很高级。
- 内部无自相矛盾；但纪元体系与游戏内已上线文本无对应关系（见契合度）。

**与游戏玩法的契合度：中高，两处硬伤**
1. **派系名硬伤**：把残存政府称"白鹰"并贯穿全文（"白鹰残存政府""法统税"），而代码显示名为"残存政府"（存档 id `tech`）。文档若被文案/TTS 直接引用，会造成 UI 与叙事用语断裂。
2. **纪年硬伤**：自创"灰烬日 2077 / 纪元 43"，而游戏已上线的第一章旁白（`campaign.js` CHAPTER_INTROS）明写"第七日"、`js` 各处与 Grok 文档的"出口-7 开门"叙事互相咬合，GLM 纪年与之不兼容。
- 数值核对基本全对：地价（60–260）、税收三档 50/75/100、保释 50、四牌堆概率、章节目标、结局阈值均与代码一致。
- 三份共有的一个错误：声称"16 条任务链"——`events.json` 实际约 14 条（11 条 `chain_*` 多步链 + `nuke_chain` + `relic_bunker→ai→choice` + `relic_map→cache`），GLM 只是虚报数量，未虚造内容。

**优点**
- 文学性第一：谚语（"尸潮一来，药价上天；军阀一死，地价落地"）、行话（"骰神罚我"）、银行行长台词，全是可直接进事件卡文案的成品素材。
- 净水修道院设定独有且聪明——解释了安全格"为什么没人敢动手"，比"默契停火"更有画面。
- 第五章"两作联动钩子"（大亨的地契 = 射击图的战场、核弹结局改变另一作世界状态）是跨产品叙事的好接口。

**缺点**
- 机制层世界观化不足（道具卡/突变/模式缺位），作为"唯一权威参照"不够用。
- "白鹰"命名与纪年体系若不修正，会污染存档用语与已上线文本。

**改进建议**
1. 将"残存政府/白鹰"统一为"残存政府"，"白鹰"可降格为民间蔑称出现在事件卡文案里。
2. 纪年体系并入正典（见第 5 章方案）。
3. 补一节"道具卡与突变因子的废土解释"（可直接抄 Grok §4.2/§4.5 的表）。
4. "16 条任务链"改为实数 14 条，或注明统计口径。
5. 地契大爆炸一节建议原样保留——这是本文档最有价值的部分，应移植进正典。

### 2.2 Grok 4.6《世界观设定_废土大亨》

**设定完整度：高**
- 独有"双栏法"：每个格子都写"在世界里是什么 / 在棋盘上怎么结算"。全部 14 类特殊格、五区地产、三哨两设施、爆心区均有机制对照。
- 机制覆盖最全：道具卡 10 张全列、突变因子 16 个逐个给出世界解释（如"无法无天 = 隔离网塌了"）、四种模式各有"世界读法"、回合上限、难度档、抵押/赎回规则。
- 历史层完整：焚年总表从 AB -40 排到 AB 32+，含六章当代史与十六条任务链的"伤口"概括。

**逻辑一致性：高**
- **盆地文明**是三份中唯一正面回答"为什么世界是一个 44 格环形棋盘"的设定（辐射尘、塌方、派系路障圈死盆地，所有路绕回一圈）——把棋盘拓扑本身写进了地理，这是桌游世界观该有的自觉。
- **爆心区**：棋盘中央玻璃化焦土 = 核弹默认落点 = 绝对胜利的视觉终点，三点一线，叙事闭环。
- 四套民间信仰（手册派/井口派/协议派/虫洞派）为道德值、事件卡选择、虫洞格提供了文化层解释，且明言"不改租金数字"——分寸感好。
- 时间纵深（25 年避难所封闭）偏短，与 MiniMax 的 137 年相比社会重建速度显得仓促，但与"玩家刚走出避难所"的开局叙事完全自洽。

**与游戏玩法的契合度：最高（本次逐项核对的结果）**
- **密钥七处掉落来源与 `js/nuke.js` 的 `NUKE_KEY_CHANCES` 完全一致**：深井铅封罐(radiation_deep 0.24)/浅层碎片(radiation_shallow 0.11)/黑市赃物堆(blackmarket_steal 0.20)/旧货箱夹层(blackmarket_card 0.14)/电台阵列废弃产线(chip_factory 0.16)/占领后机密保险柜(chip_factory_owner 0.26)/手册夹层(manual 0.15)——一字不差，连"占领电台阵列后改走保险柜"这个分支都写对了。
- 密钥顺序"阿尔法→布拉沃→查理，拒绝乱序"与代码注释原文一致。
- "第七日""隔离区警报仍在远处嗡鸣""独狼还是领路人"等措辞与 `campaign.js` 已上线的第一章旁白逐句咬合——这份文档是照着游戏实际文本写的。
- 其余数值全部核对无误：绿洲 +25、赏金 100/60、黑市偷袭 80、淘卡 120、矿洞深采 80→150 / 浅采 40→70（含道德 −1）、铁路 25/50/100、设施 ×4/×10、保释 50、安全格 2 格、抵押半价/赎回 55%。
- 唯一的小偏差："格子顺序每局洗牌"——代码里 `shuffleBoard()` 确实存在，但它是 `randomBoard` **可选项**而非默认行为，文档表述略绝对化。
- 同样虚报"十六条任务链"（实际约 14），表格中"货运坠毁""反应堆/爆心"实为单张事件（`fo76_cargobot`/`fo76_reactor`）而非链。

**优点**
- 数据忠实度第一，可直接当开发参照。
- "约法"十条（存档 id 不改、密钥顺序固定、瓶盖唯一货币、道德不改数值只改叙事等）是团队防设定漂移的护栏，工程价值极高。
- 灰日三幕与核弹过场同构（"便于语音与分镜复用"），是唯一考虑到资产复用的文档。

**缺点**
- 文学感染力明显弱于 GLM：准、但干，缺少能直接抄进事件卡的谚语与人物口吻。
- 派系刻画篇幅最短（各只有四五条），"大亨时代为什么在这个时间点爆发"的动机不如 GLM 的地契大爆炸有力。
- 中立势力（黑市账房、遗迹猎人、门卫等）只有一句带过，GLM 的"净水修道院"明显更成体系。

**改进建议**
1. 作为正典基准，吸收 GLM 的"地契大爆炸"作为时代动机章，替换"开门后自然形成大亨时代"的平淡表述。
2. 派系一节扩写：借用 GLM 的派系口吻表（"救援先于立场"等）与 MiniMax 的声望五档行为表。
3. "每局洗牌"改为"可选的乱序开局（randomBoard）"。
4. 任务链数量与"货运坠毁/反应堆"的链/单事件属性修正。
5. 补一段与《废土残页》/射击项目的联动钩子（GLM 第五章现成可抄）。

### 2.3 MiniMax《世界观设定_origin.md》

**设定完整度：高（形式上最全）**
- 十章 + 两附录，产品手册级：棋盘 ASCII 结构图、五区色值（含十六进制）、四牌堆逐堆卡量、十六条链逐条（含链 ID、起承结、道德影响、奖励）、声望五档带数值区间与派系行为、派系终局、核弹发射全流程、四模式、25 个突变因子全 ID 表、7 种叙事传承、遗产商店价格表、道具卡表、名词对照表、文档维护规约。
- 它是三份中唯一把"文档如何随代码演进"写成流程的（附录 B：新增格子/事件/链/因子 → 同步哪一节 + 哪个文件）。

**逻辑一致性：中**
- 137 年时间线（回响 → 长灰 R.A.1–100 → 当代 R.A.137）最宏大，但与开局叙事错位：游戏开局是"你推开避难所的生锈铁门，口袋 1500 瓶盖"——一个世界已重建 137 年、五区派系格局成熟的废土，玩家却像刚出避难所。硬圆可以说"你是最后一批出仓者"，但与 Grok 咬合游戏文本的"第七日"相比，明显是平行创作。
- 自造专名密度最高：阿帕拉契亚联邦 Sector-7、响者革命、铁锤麦克森、冰湖停战（R.A.132）、1873 次爆炸、1.2 亿→7 万人口。作为架空设定本身自洽，但**"铁锤麦克森"是 Fallout 钢铁兄弟会的姓氏（Maxson）、"Enclave"是 Fallout 官方派系名**——对一个不公开的个人项目问题不大，但属于原样挪用别家 IP 专名，建议替换。

**与游戏玩法的契合度：中（对得多，错得也多）**
- **对的部分**：突变因子 25 个及 ID（`double_rent`…`nuke_race`）全表与 `mutators.js` 一致；叙事传承 7 种名称 6/7 吻合；遗产商店 6 项与价格（50/120/80/100/60/150）与 `legacy.js` 逐项一致；道具卡 10 张与效果、手牌上限 4；声望 -100~+100；牌堆权重 30/30/20/20；章节目标与结局阈值；棋盘 44 格五区地价。
- **错的部分（本次逐条核对确认）**：
  1. 绿洲 +30 盖 → 实际 **+25**（`rules.js` oasis 函数）；
  2. 国会掩体在"格 31"（附录写 tile-32）→ 实际**索引 30**；
  3. 事件格 8 个 → 实际 **6 个**；
  4. 铁路 4 格（"三哨 + 隐含交通"）→ 实际 **3 格**；
  5. "16 条任务链"中 **chain_blackmarket_1/2/3、chain_route_1/2、chain_enclave_1/2/3 三条链在 `events.json` 中不存在**（实际链约 14 条）；
  6. 叙事传承"破产 → 浴火重生" → 实际第七种是 draw"**命运中断**"；
  7. 派系终局三事件（灰堆王座·麦克森接见 / 冰湖协议·仁心勋章 / 三哨准入·密钥授予）在数据中**无对应实现**，属未落地设计；
  8. 核弹视觉"棋盘中央替换避难所出口贴图"与本文档自己的"视觉中心是避难所圆环"自相矛盾，也与 Grok 的"爆心区"设定冲突。
- 总体像是对着某个版本的代码（或自己的想象）写的：框架和大部分数据可靠，**逐条引用前必须核对**。

**优点**
- 最适合当"设定维基 + 维护手册"：名词对照表把关键词→含义→文件/id 全部打通，新人接手成本最低。
- "**买色即站队**"（五区颜色 = 派系颜色，垄断一片色就是向一个派系表态）是三份中最妙的玩法-叙事绑定，一句话把大富翁的核心行为翻译成了立场表达，建议必收。
- 声望五档带派系行为（盟友主动派兵/商店折扣；死敌悬赏人头）给了声望系统明确的体感预期。
- 设计三原则（世界观要素必须有玩法承载 / 新增叙事优先走 JSON / 玩法必须有世界观解释）应该写进团队 wiki 首页。

**缺点**
- 错误条目最多（上列 8 处），作为"唯一权威参照"不可信；
- 文学性最弱，几乎没有可直接进事件卡的文案；
- Fallout 专名挪用（Maxson/Enclave）有 IP 卫生问题；
- 137 年纵深与开局叙事的错位需要裁定。

**改进建议**
1. 按第 4 章核查表逐条修正后，降格为"数据对照手册"使用，不再承担正典职能。
2. 三条未落地的链（blackmarket/route/enclave）与派系终局：要么按第 6 章列入"待实现设计提案"，要么删除，避免与现有 `events.json` 混淆。
3. "铁锤麦克森"改原创名（如"铁锤"留名不留姓，或换成"灰烬王座·锤哥"这类自造诨名），"Enclave"后缀删掉。
4. 时间线若保留 137 年，需明确"玩家是 137 年后最后出仓者"的补丁设定；否则并入焚年体系。

## 4. 文档声称 vs 代码实际 · 核查总表

**仅 Grok 正确**：密钥七处来源与掉率（`NUKE_KEY_CHANCES`）；密钥固定顺序；"第七日"叙事与 `CHAPTER_INTROS` 咬合；绿洲 +25。

**仅 MiniMax 正确**：遗产商店价格表；声望五档区间；突变因子逐 ID 表（Grok 未列 ID）。

## 7. 结语

三份文档是三种典型：**GLM 写的是"历史"，Grok 写的是"宪法"，MiniMax 写的是"档案"**。一个世界观项目恰好三层都需要——但现在它们互相打架（三套纪年、两个棋盘中心、一个幽灵派系"白鹰"）。

建议的最终形态：一份 Grok 骨架的正典（含约法），内嵌 GLM 的血肉（地契大爆炸与全部文学资产），背后挂一份修订过的 MiniMax 式对照手册（数据与维护规约）。三层各司其职，后续所有事件卡文案、美术、章节叙事都从这三层里取材，不再各说各话。
