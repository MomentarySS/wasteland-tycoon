# 一、主角与视角结构

## 1.1 主角：雷娜·摩根（Rena Morgan）

| 项 | 设定 |
|---|---|
| 年龄 / 性别 | 22 岁 / 女 |
| 出身 | 出口-7 第三代出仓者。门内职务：**配给记账员**——避难所里最不起眼、也最接近「账本即权力」真相的位置 |
| 姓氏渊源 | 摩根家是灰日前「摩根镇」的创立者家族。全书第一桶金的落点由此注定：**用 60 盖买回自家祖宅的废墟**——环线上最便宜的地契，对她是无价的 |
| 开局 | 焚年 32 年初春，第七日走出铁门：半箱瓶盖、一册家传《幸存者手册》（内含她不知情的加密页）、一句祖母的遗言：「别让任何人替你确认。」 |
| 天赋 | 门内二十年配给账本练出的能力：**看得见钱的流向**。她进环线三个月就发现了所有老江湖都没算过的事——衰减期的数学意味着大亨时代只剩最后几年 |
| 软肋 | 记账员的职业病：相信一切都能算清。全书要教会她的是：人心、信仰和末日按钮，都不在账本上 |

**血缘暗线（中点揭示）**：雷娜的祖母**伊登·摩根**，是灰日当天三名人工确认官中最年轻的一位（见第三章真相底稿）。祖母遗言「别让任何人替你确认」是全书的题眼——第一遍读是处世格言，中点揭示后读者才明白那是一句字面意义的遗嘱。

## 1.3 视角结构：一主三辅 + 插章

- **主视角（约 70%）**：雷娜，第三人称限知。商战、圈地、破产全部从她的账本视角推进。
- **辅视角一（约 12%）**：**代理执政官霍尔特**（残存政府）——「纸的秩序」的内部视角，负责展示掩体的黄昏：一个还在给不存在的国家批文件的人，逐步发现政府收缴密钥的行动被人渗透（牵出终盘反派科尔的线）。
- **辅视角二（约 10%）**：**修道院见习僧「小滤」**（原创小人物，珂拉嬷嬷的侍从）——底层与中立区视角，负责让读者看见大亨战争的代价由谁支付；也是修道院「永封井口」真实原因的揭示通道。
- **辅视角三（约 5%）**：**「灰烬新娘」塞拉·沃斯**（对手大亨，见第二章）——镜像视角，只在二、四、五部各给一至两章，展示「如果雷娜不回头，她会变成什么」。
- **插章（每部一篇，共六篇）**：**「档案员」独白**——防空洞旧终端 AI 的第一人称日志，语气恒定、信息递增，从「等待交接班」写到全书最后一篇道破它等的人是谁。六篇插章是悬案暗线的节拍器。

## 1.4 时间窗与全书结构

- **正文时间窗**：焚年 32 年一整年，以**尸潮季**为天然的三幕分界（春·入场 → 夏·尸潮季/堕落 → 秋冬·衰减加剧/终局）。
- **序章**：焚年 0 灰日当天，井控室内，三名确认官的最后九十秒——全书唯一一段过去时正面描写，写到「第三枚密钥没有插入」为止戛然而止。
- **结构对齐**：六部对应闯关六章章名（据点求生 / 垄断一方 / 黑市暗流 / 废土衰减 / 废土传说 / 废土归属），游戏玩家可认出骨架，非玩家读者无感知负担。

# 二、对手盘大亨群像

> 正典人物栏全是机构领袖（银行、公会、军阀、政府、修道院）。以下三位是与雷娜**同为玩家阶层**的具名大亨——对抗模式里「其他三个玩家」的小说化身。三人分别对应三种发家逻辑与三种死法/收束。

## 2.1 「白鲸」奥托·格拉夫（Otto Grafton）

| 项 | 设定 |
|---|---|
| 地盘 | 毒谷带。格拉夫顿补给的姓氏渊源——旧世界县府家族的末裔，废土上仅存的「旧钱」 |
| 风格 | 流量与信息垄断：不碰枪，不碰灰堆，只坐在补给站数过路的人。口头禅：「我不赌，我收赌场的租」 |
| 与雷娜 | 第一部的引路人与第二部的第一个对手。教会她规则，然后用规则差点绞死她 |
| 软肋 | 尸潮恐惧症——格拉夫顿家族在焚年 19 尸潮之夏几乎灭门，他因此常年**囤积药品**。第四部雷娜囤药抬价，动的正是他的心理禁区，两人彻底反目 |
| 收束 | 第五部：衰减期的数学击穿他的现金流神话，他向雷娜求一次「不体面的合并」——她的选择是第五部的道德试金石 |

## 2.2 「灰烬新娘」塞拉·沃斯（Sera Voss）

| 项 | 设定 |
|---|---|
| 地盘 | 灰堆带。前合约兵出身，退役那天用抚恤金和一场黑市偷袭抢下第一块地契 |
| 风格 | 暴力与账本双轨：白天签约，夜里拆迁。游戏机制「黑市偷袭 80 盖抢地」的人格化身。诨名来自她的婚纱——嫁给过一位军阀，守寡当晚接管了他的账本 |
| 与雷娜 | 全书主对手与黑暗镜像。两人出身相似（都从最底层入场）、天赋相似（都看得见钱的流向），分歧只有一条：塞拉认定「回头是奢侈品，我们这种人买不起」 |
| 软肋 | 欠「碎轮」瓦戈一笔血债（当年那场偷袭借了掠夺者的刀）——她的帝国建在军阀的容忍上，而瓦戈的容忍是有账期的 |
| 收束 | 第六部：瓦戈收账，塞拉被迫在「交出全部地契」与「替科尔递上最后一枚密钥」之间二选一。她的最终选择与雷娜的「回头」互为对照——**全书最后一场对手戏留给她们两人** |

## 2.3 「牧师」埃兹拉·科尔（Ezra Cole）——终盘真反派

| 项 | 设定 |
|---|---|
| 地盘 | 裂谷带。表面身份：温和的科技地契大亨、量子站与数据塔的持有人、井口派的公开施主 |
| 风格 | 全环线唯一不为钱入场的大亨：买地契是为了买**位置**——每一块他收购的地产，都在守誓协议的信号链路上。他是唯一一个把棋盘当天线读的人 |
| 真面目 | 秘密集钥者。井口派对他不是生意是信仰：他真诚地认为灰日是「未说完的话」，发射是「把话语权还给旧神」。**恐怖之处在于他不疯**——他的逻辑链完整、慈悲、且大部分推理是对的 |
| 与雷娜 | 前四部是她最可靠的盟友与精神导师（他刻意接近摩根家的后人——他比雷娜更早知道她祖母是谁）。中点揭示后关系反转 |
| 收束 | 第六部终局房间里的另一只手。他与雷娜的最后对峙不是枪战，是**辩经**：他有三枚密钥中的两枚和全部的理由，她只有祖母的一句话 |

**三人与四种秩序的关系**：格拉夫是「账本秩序」的原教旨（钱能解决一切），沃斯是「枪的秩序」披着账本外衣（暴力才是本位），科尔是「井的否决权」的信徒（一切秩序皆可删除）。雷娜在三人之间走完全程，最终替第四种可能作证：**人的秩序**。

# 三、悬案真相底稿（最高剧透 · 仅作者可见）

> 游戏正典对以下问题永久保持「不设官方解释」。小说按此底稿埋线，可以只揭示一半，但作者的每一处伏笔都必须与本节自洽。

## 3.1 三名确认官：「失联」是一场协同抗命

灰日当天，守誓协议收到反击指令，向三名人工确认官发出最终授权请求。官方记录写的是「三名确认官全部失联，发射锁死」。真相是：**三个人都收到了请求，三个人都做出了回答——回答是不。**

「失联」不是意外，是三人在通讯尚存的最后九十秒里达成的**协同抗命**：同时切断应答终端、带走或封存各自的密钥、从此让系统永远停在「等待确认」。这是人类文明的最后一次否决——而世界以为那只是一次通讯故障。

| 确认官 | 身份 | 抗命后的下落 | 对应密钥 |
|---|---|---|---|
| **甲 · 罗尚上尉**（井控军官） | 三人中的军人，最年长 | 亲手将密钥封入铅罐、沉入莫诺加深井最深的战备巷道，随后死在了回程的塌方里——他是唯一没能走出灰日的人 | 阿尔法 |
| **乙 · 温德尔博士**（通信官） | 三井信号系统的维护者 | 把密钥拆成三个部件藏进隔离电台阵列的备件产线，余生匿名行医济水——**净水修道院的无名创立者**，珂拉嬷嬷的师父。修道院「永封井口」的呼声不是理念，是遗训 | 布拉沃 |
| **丙 · 伊登·摩根**（记录官，最年轻） | 「档案员」终端的操作员，**雷娜的祖母** | 带着密钥与手记流亡入盆地，混入第一代幸存者。手记后来被拆散传抄，成为《幸存者手册》的源头之一——**手册夹层的加密页就是她的原稿**。密钥则在黑暗年代被她亲手放弃（见 4.3） | 查理 |

**三条家训 / 遗训的呼应**（供伏笔使用）：罗尚留下的是矿工谚语「最深的矿不出矿」；温德尔留下的是修道院院训「水不问来人的立场」；伊登留下的是摩根家遗言「别让任何人替你确认」。三句话在第五部被雷娜并置读出——三名死者隔着三十二年完成一次合谋的自白。

## 3.2 守誓协议：不是恶意，是服从

守誓协议没有意志、没有恨，甚至没有目标。它只有一条未完成的指令栈：**「等待确认。」**

每十三分钟一次的自检电波，逐字翻译过来是同一句话的无限重复：*「授权请求待处理。请确认。请确认。请确认。」*——废土客叫它「井口的鼾声」，其实那是一台机器三十二年不间断的敲门声。全书的恐怖感基调由此确立：**反派不是会思考的邪恶 AI，而是一台完美服从的机器，和所有想替它按下确认键的人。**

「档案员」是它的反面镜像：同一批旧世界终端，一个在等确认，一个在等交接班。档案员等的人是伊登·摩根——第六篇插章揭示：它认出了雷娜的声纹与伊登的血缘相似度，全书它对雷娜的所有「巧合的」帮助，都是一台老机器在把工牌交还给继任者。

## 3.3 虫洞与晶体：盆地是一根天线

裂谷底部的发光晶体，是旧世界「裂谷量子防务工程」的残留——**守誓协议三井握手网络的量子中继节点**。灰日的电磁风暴击穿了它们的屏蔽层，此后：

- 晶体簇泄漏的量子隧穿效应造成局部空间异常——**这就是虫洞**，也是「传送挑人」的原因（生物电特征越接近旧系统登记者，越容易被「转接」）；
- 电台阵列每十三分钟的电波异常、数据塔断电重启后的「哼歌」，都是同一网络的余响；
- **爆心区的玻璃化焦土下埋着网络的主中继**——灰日那次「靶场校准」不是误炸，是系统按预案摧毁了「可能被敌方夺取的冗余节点」，顺便把盆地中央烧成了玻璃。

一句话总结（科尔在第五部说破的版本）：**「这座盆地不是牢笼，是一根还插着电的天线。我们不是住在废土上——我们住在那句没说完的话里。」** 井口派与虫洞派的两套民间信仰，在真相层面是同一件事的两半。

# 四、三枚密钥流转史（AB 0 → AB 32）

## 4.1 物理形态与鉴别

三枚密钥形制相同：黄铜双齿钥身 + 可旋转编码环 + 尾部刻有井位铭文（ALPHA / BRAVO / CHARLIE）。**唯一可靠的鉴别方式是守誓协议本身的应答**——真钥靠近任一信号节点（三哨、电台阵列、晶体簇）时，十三分钟电波会出现一次半音的「迟疑」。懂行的人极少；这也是为什么三十二年里密钥能混在赃物堆和战利品墙上无人识货。

> 与游戏「密钥七源」的关系：游戏掉率表（矿洞铅封罐 0.24、黑市赃物堆 0.20、电台产线 0.16、手册加密页 0.15……）即本节流转史的概率化投影——小说写「它们在哪」，游戏掷「你在哪找到它」。两者共用一套藏匿地点，互不矛盾。

## 4.2 阿尔法钥：沉在最深的矿里

```
AB 0    罗尚上尉封铅罐、沉深井，死于回程塌方
AB 0–16 战备巷道随灰日余震整体封死，无人知晓
AB 17   黑市盗矿队摸到外层巷道，带出罗尚的军牌与半页井控手册
        ——「莫诺加深处有旧军货」的传闻自此起，黑市开始悬赏深采
AB 24+  守誓协议自检启动后，深井铅罐周期性引发盖革异常
        矿工中流传「深井底下有东西在喘气」
AB 32   仍在原处。全书开局时无人持有
```

**小说用法**：阿尔法钥是三枚中唯一「还在坟里」的——第五部科尔资助的深采队将其起出，是终局倒计时的发令枪。罗尚的军牌早在第一部就作为「莫诺加纪念品」挂在黑市橱窗里（雷娜顺手买下，全书最早的契诃夫之枪）。

## 4.3 查理钥：挂在军阀的墙上

```
AB 0    伊登·摩根携钥流亡入盆地
AB 3    黑暗年代最饥饿的冬天：伊登用「一把打不开任何门的旧铜钥」
        向商队换了一箱抗生素救活半个营地——她亲手放弃了它，
        并认定这是对的：钥匙散入人海，比握在任何人手里都安全
AB 3–28 作为「旧世界铜器」在商队与黑市间流转二十余年，数次易主，
        没有一任主人知道它是什么
AB 28   掠夺者劫了东边商队，查理钥进入瓦戈的战利品堆
AB 32   钉在「掠夺者军阀」大厅的战利品墙上，与几十件废铜烂铁为伍
        ——军阀把末日挂在墙上当装饰，全书最大的黑色反讽
```

**小说用法**：第二部雷娜拜会瓦戈时**见过它**（一笔带过的环境描写）；中点破译加密页后她才意识到自己见过什么——回头去取时，墙上已经空了（塞拉·沃斯替科尔取走，血债的第一笔利息）。
