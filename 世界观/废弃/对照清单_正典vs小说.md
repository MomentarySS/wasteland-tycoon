## 一、世界背景与末世成因

### D1-1 `必须修改` 序章「服役三十年」与三井竣工年冲突

- **位置**：`novel/序章_最后九十秒.md` 第 31 行
- **类型**：时间冲突
- **原文**：一枚战术弹头准时抵达了它**服役三十年**来的第一个、也是最后一个目标
- **正典依据**：`final/废土大亨` 3.1 焚年总表 — 「AB −18 三井竣工」→ AB 0 灰日 = **18 年**
- **建议改为**：一枚战术弹头准时抵达了它**服役十八年**来的第一个、也是最后一个目标
- **备选（更有味道）**：它等了十八年，才等到第一个目标——然后就没有第二个了

### D1-2 `必须修改` 序章「二十六年的条令」同 D1-1 根因

- **位置**：`novel/序章_最后九十秒.md` 第 17 行
- **类型**：时间冲突
- **原文**：**二十六年**的条令长在他的脊椎里
- **建议改为**：**十八条令**长在他的脊椎里
- **或（若想保留军龄与井龄两个层次）**：他当兵二十六年，在这张椅子上坐了十八年——条令比军龄更早长进脊椎
- **备注**：与审稿报告 C1 重出；本轮新增依据是正典 3.1 的「AB −18 三井竣工」硬数据，故升格为必须修改

### D1-3 `可选优化` 战线 1.1 丢失了「圈死」这个核心比喻

- **位置**：`final/废土战线` 1.1 第 31 行
- **类型**：概念遗漏
- **原文**：阿帕拉契亚盆地。灰日（焚年 0）的核爆把它撕开，焚年 25 出口-7 开门后它重新变成可争夺的环形领地
- **正典依据**：`final/废土大亨` 1.1 —「被辐射尘、塌方和派系路障**圈死的盆地文明**」「盆地外是更高的盖革读数……盆地**内才有灯、水、枪和名字**」
- **建议改为**：阿帕拉契亚盆地。灰日把它烧出一圈边界——外面是更高的盖革读数与更密的尸潮，里面才有灯、水、枪和名字。它不是被炸开的废墟，是**被圈死的围城**
- **理由**：「围墙」是本 IP 世界观的地基（棋盘=环形、44 格=一圈、衰减=围墙在收缩），战线简化为「核爆撕开」把这层丢了

### D1-4 `可选优化` 战线未区分「自毁」与「互毁」

- **位置**：`final/废土战线` 1.1 第 33 行、4.1 时间锚点
- **类型**：概念遗漏
- **原文**：灰日（焚年 0）的核爆把它撕开 ／ AB 0 灰日。中央靶场核平
- **正典依据**：`final/废土大亨` 1.3 第 4 条 —「**别处的弹头没有停**。中央焦土由旧国自己的靶场校准误炸生成」
- **建议改为**：中央那一下是自己人打的（靶场校准）；盆地边缘那些，是敌人打的。**那一天废土挨了两轮核爆，只有一轮是自己按的**
- **理由**：这是全书最大的反讽，战线完全没体现

### D1-5 `可选优化` 序章「资源战争打到第二年」的表述

- **位置**：`novel/序章` 第 5 行
- **类型**：措辞歧义
- **原文**：资源战争打到**第二年**
- **正典依据**：`final/废土大亨` 3.1「AB −2 资源战争爆发」、1.3「资源战争的最后两年」

- **理由**：AB −2 爆发 → AB 0，含首尾是第三年、按整年是第二年，两种算法都成立，需锁死一种

## 二、势力派系与组织架构

### D2-1 `必须修改` 小说「第四种可能」与正典「五种秩序」错位

- **位置**：`novel/小说前置设定` 2.3 末段
- **类型**：体系冲突
- **原文**：格拉夫是「账本秩序」的原教旨，沃斯是「枪的秩序」披着账本外衣，科尔是「井的否决权」的信徒。雷娜在三人之间走完全程，最终替**第四种**可能作证：**人的秩序**
- **正典依据**：`final/废土大亨` 4.3 — 共**五种**：枪（掠夺者）／人（响应者）／纸（残存政府）／账本（银行公会）／井（守誓协议）
- **问题**：小说三人只覆盖三种（账本、枪、井），**漏掉了「纸的秩序」（霍尔特）**，却把「人的秩序」编为「第四种」——而它在正典里是五种之一，不是第四种
- **建议改为**：格拉夫是「账本秩序」的原教旨，沃斯是「枪的秩序」披着账本外衣，科尔是「井的否决权」的信徒——而霍尔特还在掩体里，替「纸的秩序」给一个不存在的国家批文件。雷娜在**四人**之间走完全程，最终替**第五种**可能作证：人的秩序——那种不写在任何账本上、只活在响应者通道上的东西

### D2-2 `必须修改` 小说重大遗漏：玛拉·凯恩（「灯火」）

- **位置**：`novel/小说前置设定` 1.2（第四部）、1.3（视角结构）、第六部终局
- **类型**：人物遗漏
- **正典依据**：
  - `final/废土大亨` 4.2 — 响应者协调人，「医疗链、水源链的**道德轴心**；**仁心结局的见证人**」
  - `final/废土战线` 2.3 — 哨卫团精神领袖；她签的合约有一条附加款：**不许摘俘虏的面罩**
- **问题**：① 小说正史结局定为「废土传说收束、以**家园建造者**余韵结尾」，而家园/仁心结局的见证人缺席；② 第四部核心事件是「尘暴季囤药抬价」，正对应正典医疗链的抉择核「**分药或囤积**」，**道德对手盘完全缺失**——雷娜在对着空气作恶
- **建议改为**：
  - 1.2 第四部补：尘暴季囤药抬价、赶尽杀绝；「营地的人不再叫你名字，他们叫你老板」——而**她囤的每一箱药对面，都站着玛拉·凯恩**。那个女人从不带枪，但全环线的路障见她都抬杆。**堕落最深点，是她第一次对玛拉关上电台的那一刻**
  - 1.3 视角结构：**新增辅视角四（约 6%）——玛拉·凯恩**，或至少把她设为第四部与第六部的核心见证人（从 12% 霍尔特 / 5% 塞拉中匀出）
- **备注**：本轮新增，审稿报告未覆盖

### D2-3 `可选优化` 塞拉的合约兵背景未指明所属部队

- **位置**：`novel/小说前置设定` 2.2 vs `final/废土战线` 2.1 / 2.3
- **类型**：关系遗漏
- **原文**：前合约兵出身，退役那天用抚恤金和一场黑市偷袭抢下第一块地契
- **正典依据**：战线 2.1「铁鸦掠袭团 = 掠夺者联军的精锐合约部队，由瓦戈麾下各血帮抽调」；2.3「瓦戈 = 铁鸦掠袭团的**终极雇主**」
- **建议改为**：前**铁鸦掠袭团**破堡手出身。退役那天，她用瓦戈发给她的抚恤金——和一场黑市偷袭——抢下了第一块地契

### D2-4 `可选优化` 小说未使用「冲突合约五条」

### D2-5 `可选优化` 小说未定义「东边商队」

- **建议**：补一句定义——东边商队来自盆地外某处，是环线上唯一还能带来外部消息的通道，也是唯一会用瓶盖之外的东西结账的客人

### D2-6 `可选优化` 小说未使用「路契大亨」这一世界内行话

## 三、关键人物及其关系

### D3-1 `可选优化` 温德尔「匿名行医」与通信官身份不符

- **位置**：`novel/小说前置设定` 3.1、4.4
- **类型**：人物可信度
- **原文**：把密钥拆成三个部件藏进隔离电台阵列的备件产线，余生**匿名行医**济水——净水修道院的无名创立者
- **建议改为**：把密钥拆成三个部件藏进隔离电台阵列的备件产线。余生**匿名修水**——他修好了旧净水站，让半个盆地的人喝上干净水，被当成圣人。**修道院叫「净水」，就是从他修的第一口井来的**
- **理由**：① 通信官修设备比行医更可信；② 直接给「净水修道院」的命名一个出处；③ 让院训「水不问来人的立场」更自然——他修的是设备，不看人

### D3-2 `可选优化` 罗尚的矿工谚语缺出身支撑

- **位置**：`novel/小说前置设定` 3.1 + `novel/序章` 第 99 行
- **原文**：罗尚留下的是矿工谚语「最深的矿不出矿」
- **建议改为**：补一句设定——**他是莫诺加矿工的儿子，参军是为了不下井。最后他把钥匙沉回了自家的矿井**
- **理由**：既解释了谚语从哪来，又让「沉井」这个选择带上宿命感

### D3-3 `必须修改` 沃斯的地盘与「掠夺者军阀」地契的关系未定义

- **位置**：`novel/小说前置设定` 2.2 + 4.3 vs `final/废土大亨` 2.1
- **类型**：逻辑冲突
- **正典依据**：2.1 灰堆区 —「**掠夺者军阀**（260 盖）：军阀本人的「会客厅」——**买下这块地契，军阀的部众给你「打工」**」
- **问题**：该格是**可购买的地契**。若沃斯持有它，她就不再是「建在军阀的容忍上」（2.2 原文），而是瓦戈的主人。底稿 2.2 与 4.3 在此自相矛盾
- **建议改为**：沃斯持有**灰堆毒巢与灰堆掠夺堡**——唯独不敢碰「掠夺者军阀」那块。**那是瓦戈的逆鳞，全环线都知道**
- **收益**：① 「建在军阀的容忍上」成立；② 给了一个具体的、可见的「不敢越界」边界；③ 第六部「交出全部地契」留下反转空间——**她最后到底买没买下那块**

### D3-4 `可选优化` 雷娜与三派领袖的关系未定义

### D3-5 `可选优化` 战线原创人物在小说中缺席

- **备注**：战线 2.3 已注明「若需进入桌游事件卡，须先回写姊妹文档人物栏」；小说属同类扩展，建议同步回写

### D3-6 `可选优化` 科尔作为「井口派施主」的阶层错位

### D4-4 `可选优化` 小说未定位修道院在环线上的两个施水点

- **建议**：小说明确两处施水点在环线上的位置（小滤视角需要具体的地理锚点）

### D4-5 `可选优化` 莫诺加矿洞与三井的巷道关系缺失

## 五、资源与经济体系

> **本节是问题最集中的维度：正典有 2 处数据与代码脱节，直接导致小说的资金规模算错。**

### D5-1 `必须修改` 正典未写「升级费用 = 地价」，小说资产规模因此算错

- **位置**：`final/世界观设定_废土大亨.md` 2.1、4.4
- **类型**：**正典数据空缺**（连带导致小说数值失准）
- **代码实测**（`js/rules.js` 第 46–47 行）：
  ```
  if (!free && p.caps < t.price) return;
  if (!free) p.caps -= t.price;
  ```
  → **每升一级，花费 = 该地产的标价；可升两级**
- **正典原文**：2.1「地产可升两级（锈蚀小屋 → 帮派堡垒），升级前须先垄断」／ 4.4「升级：垄断后投入瓶盖升两级」——**均未写费用**
- **实际成本对照**：

  | 标的 | 只买 | 满级总投入 |
  |---|---|---|
  | 摩根镇废场 | 60 | **180** |
  | 垄断森林带（6 块） | 460 | **1380** |
  | 掠夺者军阀 | 260 | **780** |

- **影响**：小说 1.1「用 **60 盖**买回自家祖宅的废墟」只算了买价；第二部「第一次垄断森林带」的真实门槛是 **1380 盖**，不是 460 盖
- **建议改为**：
  - 正典 2.1 补：**升级费 = 地价，两级封顶**（满级总投入 = 地价 ×3）
  - 小说：按上表重新校准六部资产曲线

### D5-2 `必须修改` 正典未写租金公式，小说「收租发财」的想象需校正

- **位置**：`final/世界观设定_废土大亨.md` 2.1、附录 B
- **类型**：**正典数据空缺**
- **代码实测**（`js/rules.js` 第 74 行）：`r = t.rent * (t.level + 1); if (isMonopoly(t)) r *= 2;`
  → **租金 = 基础租金 × (等级 + 1)，垄断再 ×2**
- **实例**：摩根镇废场（rent 4）→ L0 收 4 / L1 收 8 / L2 收 12；**垄断后** 8 / 16 / **24**
- **正典原文**：2.1「同色全控且未抵押 = 垄断，该组租金 ×2」——**未写等级倍率**
- **影响**：60 盖买的地，满级垄断单次也只收 **24 盖**，回本需被踩约 7–8 次
- **建议改为**：
  - 正典附录 B 补租金公式
  - **小说的商战描写必须体现这一点**：光收租发不了财。真正的钱在**据点补给（200 盖/圈）**、事件牌、赏金与投机里。**地契不是收入，是杠杆；租金只是利息**

### D5-3 `必须修改` 小说开局资金与桌游数值体系的关系未定义

- **位置**：`novel/小说前置设定` 1.1「半箱瓶盖」
- **代码实测**（`js/difficulty.js`）：简单 1800 / **标准 1500** / 噩梦 1100；据点补给 220 / **200** / 160
- **正典依据**：`final/废土大亨` 附录 B「开局 1500（简单 1800 / 噩梦 1100）」✓ **正典此处准确**
- **问题**：小说未声明是否沿用该数值
- **建议改为**：在底稿中写死一句——
  > **小说开局 = 半箱瓶盖 250 盖。这是叙事选择：雷娜是赤贫出仓者，起点远低于环线上的标准大亨（桌游标准开局 1500 盖）。她全部的故事都从这个差距开始。**
- **理由**：把「与正典不一致」转化为「刻意的落差」，同时给六部一个清晰可感的爬坡目标——**250 盖 → 1380 盖（满级垄断森林带）**
