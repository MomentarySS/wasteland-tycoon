## 约法（先于一切叙事的铁律）

1. **棋盘即世界。** 44 格环形路径是盆地文明的压缩模型，不是换皮装饰。
2. **五区名称与三派存档 id 不得更名**：掠夺者 `eagle` / 响应者 `survivor` / 残存政府 `tech`。
3. **瓶盖是唯一硬通货**，不引入第二货币。
4. **密钥只认 阿尔法 → 布拉沃 → 查理**，乱序无效；核弹是绝对胜利，不是普通奖励。
5. **三派都不是天然善恶**；玩家无强制阵营，立场跟着利益走。
6. **道德改命运，不改租金公式与骰子。** 抉择累积成章节旁白、闯关任务偏好、部分事件结果与通关结局。
7. **地点永恒，路径每局可重铺**（乱序开局为可选项）；据点固定第 0 格；棋盘中央是爆心区。
8. 隔离区可以因突变失效，但不能从世界上删掉。
9. 虫洞是异常，不是日常快捷旅行。
10. **未实现的系统一律写入第六章「扩展空间」**，不得混入正文当作现状；新增格子先改 `tiles.json` 与本文第二章，再改规则代码。
11. 射击玩法不写进本文；纪年、地名、人物与三井真相以本文为准。

# 第一章 · 世界背景

## 1.1 这片土地叫什么

官方残档仍写着「阿帕拉契亚行政区」。幸存者口头只叫**废土**，电台报时叫**棋盘**——因为所有还能走的路，最终都绕回同一圈：从避难所出口出发，穿过森林、毒谷、灰堆、裂谷、沼泽，再被铁轨和税卡拧回起点。

世界不是无限开放的沙盒。它是一座被辐射尘、塌方和派系路障**圈死的盆地文明**。盆地外是更高的盖革读数、更密的尸潮走廊，以及已经没有回声的旧国边境。盆地内才有灯、水、枪和名字。

盆地中央有一块玻璃化的焦土。棋盘上称作靶场，《幸存者手册》称作**爆心区**。风从那里刮出来，带着旧日核爆的热尘。三座导弹井的默认落点，至今锁死在这块焦土上。

## 1.2 大熄灯以前：镀铁时代

灰日之前的最后几十年，被后世称为**「镀铁时代」**——文明抵达了它最后的巅峰，也抵达了透支的极限。阿帕拉契亚是旧世界的能源、军工与生物实验走廊：

- 浅层煤矿、深井铀矿与管道网把**森林区**拧成工业肺叶；
- **毒谷区**堆满化工与军火转口，黑市的前身就是合法的「战时配给交易所」；
- **灰堆区**是露天矿与焦化带，烟雾常年压着河谷；
- **裂谷区**承接数据、量子通讯与自动化防务——三井发射协议的大脑长在这里；
- **沼泽区**被划成隔离试验场：培养池、样本库、蔓越莓基因场，名义上是农业复兴，实际上是生物保险柜。

旧国会在裂谷边缘修了一座**国会掩体**，对外称民防示范工程，对内是战时指挥备份。阿尔法、布拉沃、查理三座导弹井沿铁路线埋入山体，由**「守誓协议」——阿帕拉契亚自动化发射系统**互相握手。发射需要三枚实体密钥依序对齐，外加三名人工确认官的最终授权。系统设计者相信：只要把最后一步留给人，人类就仍握有否决权。

他们错了。**机器没有否决权，只有执行权；而人，会失联。**

## 1.3 灰日（焚年 0）

资源战争的最后两年，旧世界为争夺聚变燃料与铀矿脉透支了一切。没有人再准确记得第一枚弹是谁先按的。废土电台把那一天叫**灰日**，手册把那年定为**焚年 0**。

已知残片，共五条：

1. 战略网络先于城市死去。电磁脉冲把屏幕打成雪花，货运机器人在半空失去航线。
2. 守誓协议收到反击指令，完成一次**「靶场校准」**——三井上电、默认落点锁定：盆地中央集结点。
3. **三名人工确认官全部失联。** 发射在最后一步被锁死。三口井、三把钥匙，原封不动留在了废土上。
4. 别处的弹头没有停。中央焦土由旧国自己的靶场校准误炸生成；五区未被一次性抹平，却被冲击波、沉降与设施连环崩溃撕开。民防避难所**出口-7**封门，国会掩体转入无菌循环，隔离区从防疫营地变成永久拘留场。
5. 活着的人开始用瓶盖记账——旧钞烧完以后，瓶盖是少数还能被所有人认作「真的」的金属：**没法造假，也没法滥发。**

灰日不是世界的结束，是**旧秩序把钥匙留在井里、把人关在门后**的那一天。而「三名确认官去了哪里」，是这个世界埋得最深的悬案——正典**不设官方答案**，只允许事件卡与遗迹链逐步逼近。

## 1.4 避难所年代（焚年 0–25）

出口-7 按民防条例封闭二十五年。门内有定额罐头、循环水，以及一部越传越像圣经的《幸存者手册》。门外，五区按各自的废墟逻辑重新长出血肉：

- 森林区的管道和天桥变成拾荒者的骨架城市；
- 毒谷区的配给所退化成摊位、枪铺和情报贩子；
- 灰堆区的矿工武装化，成为最早的掠夺堡；
- 裂谷区的数据塔与电台阵列仍间歇自检，像一具不肯断气的机器尸体；
- 沼泽区的培养池外溢，雾把公路吞成走廊。

**响应者**从旧急救志愿网重生，专门抢回伤员和干净水。**掠夺者**在灰堆完成第一次「军阀联合」。**残存政府**缩在国会掩体与裂谷设施里，用无人机采样、用税卡证明自己还是「国家」。

## 1.5 开门与第七日（焚年 25）

焚年 25，出口-7 的铁门按条例解锁。对门内的人来说，那一天不是解放——是**他们自己的末日**：定额秩序终结了，往后每一口水都要自己挣。所以出仓者把开门那天叫「小灰日」，把踏出铁门后的第七天，叫**「第七日」**——按老规矩，七天不倒下，才算在废土上活了一个人。

**门开了，人没有一次走光。** 约三分之一的人选择留在门内——他们管这叫「守着壳」。避难所此后转为自愿聚居：公共库存按人头记账为**存量份额**，留下的人按日消耗自己的份额，**出仓者可一次性把名下余量折算成瓶盖提走**，废土上管这笔钱叫**「出仓结算」**。铁门开了七年，门内还剩几十号人在耗最后一点存量——他们不是不想走，是**走不动，或者无处可去**。这也是为什么到了焚年 32，环线上仍有人揣着避难所库存入场（见 1.7）。

闯关叙事的第一章就定格在这一天：*隔离区的警报还在远处嗡鸣。你攥着最后半箱瓶盖，踏出铁门——身后是秩序，前方是废土。营地的人看着你：是独狼，还是领路人？*

## 1.6 合约战争与地契大爆炸（焚年 27–30）

开门后的头两年是抢的时代。净水厂、弹药作坊、矿洞、电站——每一处能产出东西的地方，都是插在所有人喉咙上的刀。五区为「资源点归谁」流干了耐心。

焚年 27，黑市公会与废土银行牵头立下**冲突合约制度**：资源点归属，由限定人数、限定时限的小队定点冲突裁决，仲裁抽成一成；本正典只保留它对大亨时代的历史影响：**全面战争被切碎成了可计价的小仗**。制度血腥、荒谬，却意外「公平」——直到所有人算清一笔账：打个矿洞，仲裁抽一成，弹药打掉三成，阵亡合约兵抚恤两成。**打完一仗，赢家也剩不下几个盖。**

焚年 30 春，废土银行行长**「平账人」维拉·西格**与黑市公会会长**「九指」洛克**联席颁布《大环线路契计划》，史称**「地契大爆炸」**。据说通过那晚，西格只说了一句话：

> *「过去五年，战争是本行的存款，和平是挤兑。现在本行想换个生意——让所有人都能把钱存进废土里。」*

计划的核心荒谬得像天才：**把大环线上四十四处资源点，全部折算成可以买卖的地契。**

- 想要矿洞的产出？不用派十个合约兵去炸——直接掏瓶盖，买下矿洞的**地契**，往后每个路过的人给你交「过路费」；
- 钱不够？地契可以**升级**——投入瓶盖把废场改建成要塞，过路费翻倍；
- 一条商路穿一个区？把**同色地契全部拿下**（垄断），这条商路的定价权就归你；
- 付不起过路费？那就**破产**，地契原地释放——你倒下的地方，就是下一个大亨的起点。

军阀们先是嗤笑「纸能当枪使？」，三个月后看着保护费收入被地契租金反超，纷纷改口——**用枪收钱要养兵，用地契收钱只要养账本。** 血没有停，只是流进了账本。血腥的产权战争，被翻译成了大富翁。

## 1.7 当代：大亨时代（焚年 32）

对局默认的「现在」是焚年 32。地契制度落地两年，环线上已经杀出了**第一代路契大亨**：有人垄断了灰堆的整条弹药链，有人囤着沼泽的净水站坐地起价。而《废土大亨》的玩家，就是这个大时代里投身大环线的**路契大亨（Road Baron）**——揣着避难所库存、亡命之徒的第一桶金、或者干脆就是胆子比命大的幸存者，在地契市场上跟旧势力、老军阀、以及彼此，斗到底的人。

当代有三条比法律更硬的法则：

1. **圈地即生存。** 无主地产谁先插旗谁收租；垄断一组区域后整组租金翻倍——整条街只认一家的旗。
2. **动脉决定生死。** 阿尔法 / 布拉沃 / 查理三哨是铁轨枢纽，裂谷电站与沼泽净水站是水电咽喉。掐住其中两条，就能让对面营地断粮断电。
3. **密钥仍在握手。** 守誓协议从未真正下线。焚年 24 起，它在频段里周期性自检，等人把三枚井控密钥重新对齐。发射后没有谈判，只有蘑菇云与绝对胜利。

同时，盆地已进入**废土衰减期**：辐射尘暴从间歇变为季节性常驻，闯关后期每过一轮，土地就从账本上刮走一层。老账房们心里都清楚这意味着什么——**地契的红利期正在结束，新的地契不再产生，旧的地契越收越紧。这个时代给了大亨舞台，也正在悄悄拆掉这个舞台。** 每一局对局，都是在塌陷的地板上跳的最后一支舞。

## 1.8 骰子：废土之神

大亨们在环线上的每一次旅行，都由一枚骰子决定走多远——这不是游戏抽象，这是**废土的日常**。环线上危机四伏：尸潮季的迁徙路线、酸雾的沉降时段、变异兽群的巡猎领地、战争机器的游荡回路——没有人能精确规划行程。商队世代相传的信条是：**「计划赶不上废土，废土赶不上骰子。」**

于是大亨们的行话里，命运就叫「掷骰」：踩中虫洞传送叫「天降鸿运」，连进两次隔离区叫「骰神罚我」。

## 1.9 人如何理解这世界

废土没有统一宗教，但有四套互相打架的解释：

| 解释 | 持有者 | 核心信条 |
|---|---|---|
| **手册派** | 响应者、多数营地 | 前人笔记比口号可靠；分享净水与药品是续命，不是慈善 |
| **井口派** | 拾荒客、部分军阀 | 三井是旧神的喉舌；握密钥者即握末日 |
| **协议派** | 残存政府 | 国家从未死亡，只是改在掩体办公；税与采样都是「恢复秩序」 |
| **虫洞派** | 遗迹猎人 | 那道蓝光是旧世界留给下一纪元的门——废土客管它叫「棋盘中央的蓝光」，其实那东西在裂谷谷底；但人们需要它长在世界的中心，所以它就长在了那里 |

这些解释**不改租金数字**，但决定事件卡里谁肯开门、谁肯分药、谁肯把晶体上缴。

# 第二章 · 大环线四十四格

> **棋盘即世界**：44 格 = 大环线（The Loop）一圈的 44 处地点。每处地点给出两句话：**机制句**（棋盘上怎么结算，与 `rules.js` 对齐）与**闲话句**（环线上的人怎么说它，可直接进图鉴与加载页）。
> 格子顺序每局可洗牌（乱序开局为可选项，据点固定第 0 格）——**路在变，地方还在**：沙暴、塌方、尸潮切断旧路、逼出新路，摩根镇仍是摩根镇，三井仍在原坐标。
> 44 格构成：20 地产 + 3 铁路 + 2 设施 + 6 事件 + 3 税 + 2 安全 + 起点 / 隔离 / 黑市 / 掩体 / 矿洞 / 虫洞 / 赏金 / 绿洲 各 1。

## 2.1 五区：颜色不是行政区划，是物资生态与收租风格

同色全控且未抵押 = **垄断**，该组租金 ×2。地产可升两级（锈蚀小屋 → 帮派堡垒），升级前须先垄断；**每级升级费 = 该地产标价**（满级总投入 = 地价 ×3）。可半价抵押、约 55% 赎回。

> 注意：**三派 ≠ 五色**。买下灰堆的地契不等于加入掠夺者——最多可以说灰堆「气口」近掠夺者、毒谷近响应者、裂谷近残存政府。森林与沼泽不属于任何派系的气口。

| 森林断墙 | 60 | 变异藤蔓爬满的旧城墙段，拓荒者沿墙根搭了棚户区。租金不高，胜在出避难所口第一站 |
| 森林加油站 | 70 | 油早干了，但地下储罐还能存乙醇燃料。商队歇脚、加水、交换情报的黑话据点 |
| 锈蚀管道 | 80 | 跨河的旧输水管网，接头处漏的水能简单过滤后卖钱。森林区民间的「自来水公司」 |
| 断裂天桥 | 90 | 塌了一半的高架桥，桥头堡被收费帮派占了二十年。买下地契，就买断了北环的咽喉 |

酸雾里长出来的市场带，地契贵，租金也贵。主导资源：弹药、药品、黑市货。

## 3.2 灰日三幕

与核弹过场同构，便于语音与分镜复用：

1. **战略警报** —— 三座导弹井同时上电，扩散协议解锁。
2. **密钥对齐** —— 阿尔法 · 布拉沃 · 查理，发射授权确认。
3. **弹头离井** —— 落点锁定盆地中央，无可拦截。

灰日那天，第三幕没有演完——确认官失联，授权中止。**守誓协议没有道德，只认密钥。有人再次集齐三钥时，同一套分镜会重演，而这一次，不会有人失联。**

## 3.3 关键事件详述

### 地契大爆炸（焚年 30）

计划颁布当月，44 处资源点的地契竞购在五区同步开拍。军阀们先嗤笑，三个月后「真香」。史家（如果废土还有史家）会记下这一笔的真正意义：**这是灰日以来第一次，废土的暴力被一张纸驯服**——不是因为纸更强，而是因为所有人都打不起了。西格与洛克没有创造和平，他们只是给战争换了记账方式。血没有停，只是流进了账本。

### 三井密钥的流转（焚年 30 至今）

守誓协议自检的电波每十三分钟从隔离电台阵列泄漏一次，懂行的人管它叫「井口的鼾声」。三枚实体密钥在灰日后的混乱中散佚：有的埋进莫诺加的铅封罐，有的混入黑市赃物堆，有的被拆成金属碎片夹进《幸存者手册》的加密页。黑市对三钥的挂牌价每月一变，残存政府宣称「依法收缴」，修道院呼吁「永封井口」，而每一个大亨都清楚一件事——**地契买下的是废土的现在。核弹，买下的是废土的未来。集齐三钥的人，将赢得一场没有对手的谈判。**

### 尸潮季（每年盛夏）

焚年 19 以来的年度灾难。真菌之心的孢子云沿固定路线北迁，沼泽段与森林南段定期戒严。对大亨们而言，尸潮季既是**灾害**（事件卡：尸潮攻防、根据地受损），也是**商机**（药品地契租金暴涨、赏金任务翻倍）。环线谚语：*「尸潮一来，药价上天；军阀一死，地价落地。」*

### 虫洞事件（焚年 23）

裂谷地震后，深谷底部的磁场开始紊乱。探谷者在谷底发现了发光的晶体簇——任何仪器都无法归类，任何检测都得到互相矛盾的结果。科学解释缺席之处，信仰涌入：有人跪拜它，有人焚烧它，有人高价收购它。真相作为长线悬念保留，**不设官方解释**。

## 4.3 核心冲突主线

一句话：**废土的未来由什么定义——枪、人、纸，还是井？**

- **枪的秩序**（掠夺者）：恐惧最诚实，保护费比税直白；
- **人的秩序**（响应者）：救援先于立场，活下去的人越多，废土才越像人间；
- **纸的秩序**（残存政府）：法统未死，登记、课税、收缴——国家只是暂时在掩体办公；
- **账本的秩序**（银行与公会，即「大亨时代」本身）：让所有人把命换成地契，用破产替代死亡；
- **井的否决权**（守誓协议）：以上四种秩序，任何一种只要抢先集齐三钥，都可以对其余所有秩序按下删除键。

玩家是第五个变量：一个无阵营的路契大亨，每一次购地、收租、抉择与拒绝，都在给四种秩序投票——而衰减季的沙漏，给这场投票加上了倒计时。**这是每一局对局的戏剧张力来源：你不只是在赢一场大富翁，你是在替一个塌陷中的时代选继承人。**

## 4.4 资源体系

### 瓶盖：唯一的账面

开局约 1500 盖（简单 1800 / 噩梦 1100），据点补给约 200 盖/圈。地契价格、租金、税收、赏金、保释金（50 盖）、拍卖加价——全部以瓶盖结算。三大来源：**据点补给**（经过起点）、**租金收入**（别人踩你的地）、**事件所得**（四牌堆与赏金格）。

### 地契经济（核心循环）

1. **购地**：无主地契按标价购入（60 盖起步，260 盖封顶）；
2. **升级**：垄断后投入瓶盖升两级（锈蚀小屋 → 帮派堡垒），**每级费用 = 该地产标价**，租金放大；
3. **收租**：对手踩中即付；**同色垄断整组租金 ×2**——拿下这条商路的定价权；
4. **抵押与赎回**：半价抵押、约 55% 赎回——废土银行唯一的温情；
5. **破产清算**：现金跌破 0 即破产；若有收租债主，地产、铁路和设施转给债主；否则全部释放回银行的无主市场，之后可被购买或主动拍卖——**你倒下的地方，就是下一个大亨的起点。**

净身家 = 现金 + 未抵押地产价格 + 升级投入。

**写作纪律**：新事件卡必须先答两问——它发生在环线的哪个地点气口？它触碰四种秩序中的哪一种？答不出的卡不进牌堆。
