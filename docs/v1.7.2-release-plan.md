## 3. 不变量与边界

- 本次**不改玩法与规则代码**，只做版本切换、构建验证与文档同步。
- 安装包体积**实测比 1.7.1 增加约 25.4 MiB**（101.1 → 126.6 MiB）：Electron 33 → 44 的运行时体积增长约 43 MB，盖过了语音清理省下的约 5.6 MB。要压回体积只能回退 Electron 主版本；若接受，则无需处理。
- 窗口 / 任务栏图标指向 `logo.svg` 而 Electron 不支持 SVG，属既存遗留，本次发布未修（见验收段）。
- 预录语音缺口（**41/286 条可播，缺 245 条**）**不在本次发布中修复**，只在发行说明里如实标注；默认「MiniMax 在线」模式下未命中由在线 TTS 兜底。
- 1.7.1 的已发布安装包不动（`release/` 为 gitignore 目录，且 GitHub Release 已存有该附件）。

## 4. 已知风险与处置

| 风险 | 影响 | 处置 |
|---|---|---|
| ★ Electron 33 → 44 跨 3 个大版本，`electron-builder` ^25 是 2024 年版本，兼容性未验证 | 打包可能直接失败 | 先升 `electron-builder`；仍失败则回退 Electron 到 33，把升级移出本次发布（独立 commit 回退） |
| GitHub Release 需上传约 100 MB 安装包 | 上传慢或超时 | 本机固定走 7897 代理；失败则重试或改用分块/手动上传 |
| 账户额度不足（`2056`） | 验收时**无法**真实验证在线语音合成 | 与 1.7.1 验收同口径：只验证 IPC / 预加载 / 配置链路存在，不伪造在线服务成功 |
| 静默安装会写入系统 | 可能残留安装项 | 使用隔离安装目录，验收后卸载并清理 |
