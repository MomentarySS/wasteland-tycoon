# 废土大亨 v1.8.0 实施计划 · prop subType + mutator 视觉变种

> 状态：规划中（2026-10-08 建立）
> 范围：**prop subType（4 型）+ mutator 视觉变种**。不含新行动格（会改变 44 格事件频率分布，风险高于收益）。
> 前置：[地形变种研究](terrain-variants.md) 提供设计草案；本文提供实测基线、实施顺序与判据。

## 1. 范围与不做的事

| 做 | 不做 | 理由 |
|---|---|---|
| prop `subType`：`landmark` / `shack` / `volatile` / `cursed` | 新行动格（auctionHouse / campsite） | 新行动格直接改变 44 格的事件分布与随机重排分布，研究稿自己警告过 |
| mutator 视觉变种（火焰 / 洪水 / 沙暴） | 第六组 prop、战役专属 tile | 属于 2.0 候选；先让 1.8.0 被试玩验证 |
| 悬停预览显示 subType 标签 | AI 针对 subType 的偏好策略 | 研究稿列为低优先级；先保证 AI 行为不突变 |

## 3. 平衡基线（实测，2026-10-08）

用 `smoke.test.mjs` 的 DOM 桩驱动真实引擎，跑 7 局全 AI 对抗（4 人局 ×5、2 人局 ×2）：

| 指标 | 实测值 |
|---|---|
| 终局最高净值 | 最低 1895 / 中位 **2779** / 最高 3051 |
| 终局回合 | 42 / 67 / 109（中位 67） |
| 存活人数 | 4 人局**全部 4 人存活**，2 人局 2 人存活 |
| 终局持有地产 | 14–25 块 |

**两个关键推论：**

1. **对局是以回合上限结束，不是以破产结束**（4 人局无人破产）。这意味着当前 AI 对局里**没有出现「单次收租压垮对手」的情况**。
2. 普通 prop 在 Lv2 + 垄断时单次收租 26×3 = 78 盖，约为中位终局净值（2779）的 **2.8%**。
   研究稿给 landmark 的估值是 312 盖 ≈ **11%**；若独占一组三家，单回合可收 **≈ 936 盖 ≈ 中位净值的 34%**。
   ⇒ 「AI 拿到即终局」的判断**被实测数据支持**，不是作者的悲观估计。

### 3.1 平衡目标（建议，待确认）

把「单次收租上限」锚定在终局净值的比例上，比拍绝对数值更稳：

| 约束 | 建议值 | 理由 |
|---|---|---|
| 极端单次收租（Lv2 + 垄断）上限 | **≤ 中位终局净值的 8%**（约 220 盖） | 现有 78 盖是 2.8%，翻到 8% 已有明显的「大奖」感，但不足以一击定局 |
| landmark 的 rent 倍率 | 不做「×3」，改为 **×2 且基础 rent 下调**，使峰值落在 ~150–220 盖 | 直接 ×3 会把峰值推到 936 盖量级 |
| shack 维护费 | 维持 10 盖，但确保**不会因现金不足导致地块废弃而卡死流程** | 需要在实现时核对「废弃」分支是否有兜底 |

> ⚠️ 这不是「禁止 landmark 一击定局」，而是把它从「AI 捡到就赢」改成「高风险高回报的策略牌」——
> 对会算账的玩家是机会，对随手买的 AI 是陷阱。这与研究稿的原始意图一致，只是把倍率调到可达成的区间。

## 4. mutator 视觉变种

- 25 个 mutator 按效果归入 3 个视觉族：**火焰 / 洪水 / 沙暴**。
- **只做表现层**：Canvas / CSS 的环境层与遮罩，**不改任何规则数值**。
- 需满足：默认状态安静；仅在 mutator 生效期间出现；`prefers-reduced-motion` 下改为静态低亮度提示。

## 6. 验证清单

**研究稿原有 10 条**（棋盘渲染、预览标签、四种机制、战役不受影响、存档透明传递等）全部保留执行。

**本计划新增：**

1. 平衡回归：≥20 局全 AI 对抗，终局净值中位与基线（2779）偏差 ≤ 15%
2. 无「一击致胜」：landmark 独占三家时单回合收租 ≤ 中位终局净值的 8%
3. AI 行为不突变：AI 的买卖决策仍只读 `type` / `group`，不读 `subType`
4. 存档往返：`subType` 经 `JSON.stringify` / `parse` 透明传递，读档后机制仍生效
5. mutator 视觉不改变规则：同一 mutator 下前后两局的经济结果分布无差异

## 7. 不变量（实施中必须守住）

- 棋盘固定 **44 格**，不新增、不替换地块
- `shuffleBoard()` 的分桶逻辑不变（仍按 `type` 分桶）
- 战役模式（`js/campaign.js`）只读 `t.type === 'prop'`，不受 `subType` 影响
- 存档格式**不升级**（仍是 v4），`subType` 作为 `tiles.json` 的静态字段透明传递
- AI 不读 `subType`，避免行为突变
- mutator 变种**只改表现层**，不改任何规则数值
