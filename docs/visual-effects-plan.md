# 废土大亨 · 视觉特效与背景计划

> 状态：既有代码、背景资源、指挥中枢与路径/事件回响均已完成；下一轮转入 Electron 实机视觉验收与性能记录
> 目标版本：v1.7.2  
> 更新：2026-09-26

## 目标

让每一次关键行动都像在废土指挥终端上完成：棋子抵达地点、玩家取得资产、设施升级、事件造成后果，都应有清晰且彼此一致的视觉反馈。

视觉方向延续现有的绿磷光雷达、锈橙警示和低饱和废土插画。动效用于表达状态、位置和结果，不作为常驻装饰。

## 当前判断

现有棋盘并不空：中心雷达、双层粉尘、扫描线、天气、地块插画和事件粒子已经提供了足够的材质细节。但背景仍会显得单调，原因是：

1. 中心雷达是唯一强焦点，外围主要由深色网格、噪点和暗角组成。
2. 环境层与当前回合、地块类型、突变或天气几乎没有关联，画面变化缺少上下文。
3. 天气直接影响整页，棋盘和侧栏同时被覆盖，空间层次不够明确。
4. 买地与升级的短效主要叠加在固定 FX 层；Canvas 棋盘本体没有对应的瞬态绘制。

## 动效原则

| 层级 | 用途 | 规则 |
|---|---|---|
| 环境层 | 表现废土天气和终端氛围 | 慢、低对比、限制在棋盘或中心雷达内 |
| 导航层 | 表现棋子移动和目标位置 | 只在落点或关键路径出现，持续不超过 650 ms |
| 状态层 | 表现产权、设施等级、突变状态 | 以边框、徽章、局部亮度和小型图标为主 |
| 冲击层 | 表现破产、核弹、重大事件 | 全屏效果只用于稀有、高后果事件 |

所有效果需保留静态或轻量替代：减少动态效果时保留颜色、标签、边框和结果文字，移除持续移动、闪烁和震屏。

## P0：地产占领协议

**目的**：强化游戏最常见、最有价值的动作“买地”，并为后续特效建立可复用的 Canvas 瞬态效果通道。

### 演出

1. 棋子落点出现锈橙定位环。
2. 中心雷达向目标地块发出一条短促扫描信号。
3. 地块边框从中性状态过渡到玩家颜色，显示 500 ms 的 `LOCKED` 标记。
4. 资产面板获得一次小幅数值确认，避免同时播放大量金币。

### 技术落点

- `js/board-canvas.js`：维护短生命周期的地块脉冲状态，并在 `drawBoard()` 中绘制描边、扫描线和标记。
- `js/fx-events.js`：保留现有坐标、粒子与标签能力，改为调用占领协议。
- `js/rules.js`：在买地、拍卖成交处传入所有者颜色和结果类型。
- `css/style.css`：定义 `LOCKED` 标记、Canvas 降级路径与减少动态效果样式。

**预算**：单次最多一条扫描线、一个描边和六个粒子；总时长 520–650 ms。

### P0 实施记录（2026-09-26）

- Canvas 主路径已加入中心雷达到目标地块的短促扫描线、玩家色边框脉冲和 `LOCKED` 标记。
- 买地与拍卖成交会传入所有者颜色；升级沿用同一瞬态通道，DOM 格子路径继续兼容。
- `prefers-reduced-motion` 下保留结果标签，移除粒子、扫描和持续位移动效。
- 已通过 `npm test`、三处新增/修改模块 `node --check`；视觉检测未发现本次新增代码的反模式。

## P1：设施展开与等级状态

**目的**：让 Lv1 棚户和 Lv2 地堡在棋盘上具有可见的成长层次。

- 免费升级使用冷白色信号，付费升级使用锈橙色信号，避免只靠文案区分。

## P1：事件频道解码

**目的**：让不同牌堆在弹窗出现的第一眼就可辨认。

| 事件来源 | 动效材料 | 颜色 |
|---|---|---|
| 废土电台 | 横向扫描线与短促电台噪点 | 磷光绿 |
| 派系密使 | 盖章式边框锁定 | 锈橙或派系色 |
| 遗迹猎人 | 两道不闭合的轨道弧和轻微像差 | 青蓝与紫色 |
| 坏事件 | 单次警报闪光和结果标签 | 红色 |

保留现有卡片翻转，但选择结果条应在 300 ms 内出现，退出动画应快于进入动画。

### P1 事件频道基线复核（2026-09-26）

- 现有 `fx-events.js` 已按事件类型提供 burst / smoke / static / warp 四类入场语义，并叠加事件插画粒子。
- 选择结果条已按好坏结果区分颜色和进出场节奏；本轮测试确认事件、存档和剧情模块未回归。
- 已补充频道印章与频道色边框：坏事件警报、派系档案、遗迹轨迹、手册现场记录均可在插画上直接识别。
- 减少动态效果模式下仍保留事件频道印章与选择结果条；暂不新增事件图片。

## P2：棋盘背景分层

**目的**：减少中心雷达之外的重复暗色区域，让背景能响应状态，同时不干扰地块文字和侧栏阅读。

### 第一阶段：不增加美术资产

- 在 `#boardCenter` 内加入低对比等高线、断续路线和区块坐标，作为雷达的静态底图层。
- 雷达扫描改为“回合开始与关键事件触发”两种节奏；常态扫描更慢、更淡。
- 沙尘、酸雨和黄昏改为棋盘容器遮罩，侧栏保持清晰。
- 将中心环境层的亮度与当前玩家、地块区域或突变状态建立一项明确联系，例如辐射突变时出现低频黄绿色边缘脉冲。

### P2 第一阶段实施记录（2026-09-26）

- `#boardCenter` 已加入低对比废土测绘底图：等高线、断裂路线和定位节点均由内联几何 SVG 绘制。
- 底图限制在中心雷达区域，透明度低于雷达与地块插画；减少动态效果时改为静态低亮度显示。
- 本轮先用内联几何 SVG 验证层次；2026-09-27 已补齐并接入 R1–R4 背景资源。

### 第二阶段：需要新增美术资产

- 生成 3 张可无缝覆盖的低对比背景图：锈蚀卫星地图、毒谷等高线、断裂工业管网。
- 每张图只在棋盘中央区域使用，透明度控制在 8%–16%，并与现有雷达图共用绿磷光和锈橙色。

## 资源盘点与新增建议

### 现有资源的适用性

`assets/ui/board-center-radar.webp`、`zone-*.webp`、`bg-dust-layer.webp` 和 `bg-lightning.webp` 均为不含 Alpha 通道的 WebP。中心雷达和五张区域纹理可以继续复用；`bg-dust-layer.webp` 与 `bg-lightning.webp` 则都是完整场景画面，不是原计划中的透明特效层。

其中 `bg-dust-layer.webp` 以低透明度全屏叠加后会引入固定的地平线和月亮构图，容易让棋盘外背景长期呈现同一种绿灰色。它应改作可选的远景底图，或在背景分层实施时由真正的颗粒遮罩替换。

### 不需要新美术资源的阶段

| 项目 | 可直接复用的资源 | 新增位图 |
|---|---|---|
| P0 地产占领协议 | 中心雷达、玩家色、现有地块插画 | 0 |
| P1 设施展开 | 现有等级图标、地块轮廓和 Canvas 绘制 | 0 |
| P1 事件频道解码 | 事件插画、牌堆颜色、CSS 扫描线与 Canvas 轨道 | 0 |
| P2 背景第一阶段 | 中心雷达、区域纹理、CSS 等高线和路线 | 0 |

`LOCKED` 标记、扫描线、轨道弧、设施线框和事件印章均应由 Canvas、SVG 或 CSS 绘制，避免为短时特效增加位图文件和加载成本。

### 背景分层最小资源包

先只制作一张验证背景层；确认它在真实棋盘中不会压低文字和棋子对比度后，再扩展为完整三张套组。

| 优先级 | 文件 | 规格 | 用途 | 生成要求 |
|---|---|---|---|---|
| R1 | `assets/ui/bg-board-contours.webp` | 1672×941，WebP，sRGB，无文字，205 KB | 中心雷达后的常驻等高线底图 | 已生成并以低透明度接入，中央区域保持低细节 |
| R2 | `assets/ui/bg-board-industrial.webp` | 1672×941，WebP，sRGB，无文字，151 KB | 暮色/工业状态变体 | 已生成；暮色天气时切换 |
| R3 | `assets/ui/bg-board-radiation.webp` | 1672×941，WebP，sRGB，无文字，85 KB | 辐射/酸雨状态变体 | 已生成；酸雨天气时切换 |
| R4 | `assets/ui/fx-dust-specks.webp` | 1536×1024，带 Alpha 的 WebP，49 KB | 替换全屏场景式粉尘层 | 已生成并接入，透明背景、稀疏颗粒、无地平线 |

R1–R4 已进入开发版；v1.7.1 已完成 Electron 安装启动验收，正式发布前仍需记录真实窗口中的文字、棋子和侧栏对比度。

### 资源风格约束

- 沿用深绿灰 `#141917`、锈橙 `#b5651d`、磷光绿 `#7fae6e` 与琥珀 `#c9a227`，但整图平均亮度低于中心雷达和地块插画。
- 背景只承载地形、路线和材质信息；可读文字、角色、月亮、天空、爆炸和建筑主体会与棋盘玩法竞争，不纳入背景图。
- R1–R3 按 16:9 单张构图使用，不要求平铺；R4 必须可平铺且带 Alpha。
- 图片接入后通过 CSS 的 `opacity` 和 `mix-blend-mode` 调整层次，不在源图烘焙高强度扫描线或闪烁。

## P2：移动路径与状态回响

- 棋子移动保留弹跳，但将逐格足迹收敛为最终落点的路径残影。
- 安全地带、辐射区、虫洞等地块使用不同轮廓语言：稳定圆环、腐蚀扩散、折叠轨道。
- 突变因子只在它实际改变规则的节点出现一次局部回响，不在每回合重复展示。

### P2 状态回响实施记录（2026-09-26）

- 移动足迹保留为短时落点残影；安全区、辐射区、虫洞新增稳定环、腐蚀虚线和折叠轨道轮廓。
- 现有地块标签继续承担结果语义，未增加常驻粒子或全屏效果。
- 未新增位图资源，保持 Canvas/DOM 双路径可降级。

## P3：性能与无障碍

1. `prefers-reduced-motion` 覆盖雷达、中心粒子、天气、事件插画和震屏。
2. 页面隐藏时暂停环境计时器和常驻动画；回到前台后恢复。
3. `#fxLayer` 设置同时存活节点上限，优先保留结果标签和产权状态，丢弃装饰粒子。
4. 核弹继续作为唯一长期的全屏冲击演出；其余效果限制在棋盘或弹窗内部。

### P3 实施记录（2026-09-26）

- `prefers-reduced-motion` 已覆盖雷达、中心粒子、测绘底图、天气闪烁、事件插画、震屏和落尘粒子；保留标签、颜色和静态确认环。
- 页面隐藏时暂停 CSS/WAAPI 动画、环境闪电计时器和天气到期计时器，恢复页面后继续剩余时长。
- `#fxLayer` 增加 120 节点上限，淘汰时优先移除装饰粒子/环，保留 `fxLabel` 与 `fxFloat` 结果反馈。
- 已通过完整冒烟测试、模块语法检查和视觉规则检测。

>
> 目标：利用中央棋盘的空白区域，提供当前回合的即时态势和下一步行动提示；不再堆叠静态装饰，也不重复右侧战报。

### 首批范围

- [x] 中央顶部态势条：回合数、当前玩家、天气/突变状态。

- [x] 中央底部目标进度：章节目标、生存回合或资产目标，按模式切换。
- [x] 棋子移动时显示短路径残影，事件触发时显示短时结果摘要。
- [x] 保留现有地块预览和低对比测绘背景，避免遮挡棋盘、棋子和操作区。

### 指挥中枢实施记录（2026-09-27）

- `index.html` 增加中央态势条、落点操作提示和目标进度。
- `js/view-core.js` 按当前回合、天气、突变、地块类型和模式目标实时更新；不显示完整玩家姓名，保留玩家短标识。
- `css/board-v2.css` 使用低对比终端条带，保留地块预览主体视觉，不遮挡棋子和棋盘格。

- `js/fx.js` 在已有逐格足迹上增加相邻地块短线段残影；跨棋盘回到起点时自动跳过长对角线，减少视觉噪声。
- `js/fx-events.js` 增加事件结算摘要；人类选择、AI 选择和空频道都会在触发地块短暂显示结果或杂音。
- `prefers-reduced-motion` 下关闭路径线段，保留静态结果文字；已通过模块语法检查与冒烟测试。

### 设计约束

- 优先复用现有数据、Canvas、SVG 和 CSS，不以新增位图作为前置条件。
- 信息只服务当前决策，不复制完整战报、玩家列表或卡牌面板。
- 默认状态保持安静；只在回合、落点、事件和目标变化时更新。
- 继续支持 `prefers-reduced-motion`，减少动态效果时保留文字、颜色和边框语义。

## 验收标准

- 玩家能在不看战报的情况下辨认买地、升级、坏事件、虫洞和辐射的结果。
- Canvas 与 DOM 降级路径都具有同等语义反馈。
- 1080p Windows 桌面上连续掷骰与事件触发不产生明显卡顿。
- 减少动态效果模式仍能通过颜色、标签和边框理解状态变化。
- 背景在 10 秒静止观察中有层次，但不会抢过棋盘格、棋子和操作区。
