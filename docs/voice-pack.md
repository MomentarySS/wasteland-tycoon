# 预录音频清单（电台节目，不是账本）

原则：只念固定旁白。玩家点完选项后念 JSON 里的 `result`；带玩家名、金额、骰点的战报只出字。

导出：`npm run voice:list`（当前 **286 条 / 约 7800 字**）。

## 要录

| 分组 | 条数 | 何时播 | 念什么 |
|---|---|---|---|
| 任务开场 | 80 | 事件弹窗打开 | `title` + `story` + `moral` |
| 任务选项结果 | 160 | 点完两个选项之一 | 该选项的 `result`（不拼玩家名、不念按钮） |
| 章节叙事 | 18 | 闯关章节过场 | 标题 + 正文（道德变体各一条） |
| 结局 | 5 | 通关胜利战报 | `CAMPAIGN_ENDINGS[].log` |
| 叙事种子 | 7 | 遗产开局 | 种子名 + intro |
| 章节达成 | 6 | 进入下一章 | 「章节达成，进入 ××！」 |
| 终局 | 3 | 全灭 / 合作通关 / 闯关倒下 | `GAMEOVER_LINES` |
| 核弹过场 | 3 | 发射分镜字幕 | 各幕 `sub` |
| 地块氛围 | 4 | 黑市 / 辐射矿 / 掩体 / 发射确认弹窗 | `SET_PIECE_LINES` |

事件每条都有 2 个选项、2 句 `result`，80×2=160，没有缺句。

## 不录（游戏里看得到字，电台不念）

**事件弹窗里的其它字段**

- 选项按钮 `choices[].text`（「死守物资（-100盖）」）——玩家正在读，点完改念 `result`
- 结算条 `formatChoiceResult`（「+100盖 · 道德-1」）——机械摘要，不是旁白
- 牌堆名 / 连锁标签（废土电台、机密频道…）

**棋盘账本（一律带人名或数字）**

买地、交租、升级、抵押、拍卖、经过据点补给、隔离、破产、用卡、虫洞落点、空频道杂音、突变因子名单、废土衰减/辐射泄漏数值、遗产点、发射密钥「某某在某处截获」。

**操作系统 UI**

超频骰、手牌、拍卖出价、拆迁/换地目标列表、遥控骰点数。卡牌名与说明只在手牌里看。

**动态句（无法预录）**

- 生存倒下：「你在第 N 回合倒下了」
- 核弹胜利战报里的玩家名（过场三幕已经念完）
- 章节 HUD 目标 / `CAMPAIGNS[].brief`（侧栏，不是弹窗电台）
- 结局小标题 `subtitle`（胜利层展示；正文 `log` 已录）

## 运行时

人类：开场 → 点选项打断开场 → 念 `result`。  
AI：不念开场，只念 `result`。  
战报 `log(..., true)` 仅留给结局 / 种子 / 章节达成 / 终局固定句。
